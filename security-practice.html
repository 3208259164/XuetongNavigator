Umami

官网 ↗原文

想要自己拥有数据又不想为此付费的开发者或小团队，Umami 正好命中。MIT 许可宽松，面板干净、读得快，无 cookie 的脚本通常让同意横幅可以直接去掉。诚实的短板是自建路线：要起一个数据库并持续更新，而不是贴一行代码然后忘掉。想要完全拥有、也享受自建或能待在免费云额度里，选 Umami。数据库超出你想照看的范围，就选纯托管工具。

Pi-hole

官网 ↗原文

自己动手的答案，在一个维度上胜过所有托管 DNS 拦截器：查询从不离开你的网络，因为服务器你自己跑。代价是维护归你，树莓派、容器或闲置机器上都行，配错一个 Pi-hole 能把事情弄坏，直到你修好。想要完全控制、没有第三方看见你的 DNS，也不介意自己当管理员，选它。不想跑基础设施的人，用 NextDNS 这类托管服务。

Mobile Verification Toolkit

官网 ↗原文

MVT 是检测高级手机间谍软件最接近经验证实地标准的工具。由国际特赦组织随 Pegasus 项目调查一同发布，它把设备痕迹与公开的入侵指标比对，已被全球的记者、公民社会组织与安全研究者使用。诚实的局限是它要求技术能力：需要 Mac 或 Linux 机器、能提取完整设备备份、还要有足够的取证背景去解读输出。它不是终端用户自助工具，但对保护高风险个体的合适人选，没有别的能接近。

ExifTool

官网 ↗原文

格式覆盖面在这里无人能比：EXIF、IPTC、XMP、GPS、厂商注记、ICC 配置，以及数百种文件类型里几十个相机厂商标签。批量审计元数据、或者清理一堆混杂归档，没有别的能接近。短板是界面：它是带大量参数的 Perl 命令行工具，学习曲线真实存在。不用 Perl 的人有 Windows 独立 exe。分享前需要核实文件里到底有什么元数据的人，工具箱里该有 ExifTool。

simplewall

官网 ↗原文

真正轻量的 Windows 防火墙，能让你看见并拦住应用的回连，没有商业套件的臃肿。这份简单的另一面是它要你自己做放行与拦截的判断，新手容易被压住，而且只做 Windows。想要对网络流量有可见控制、也有一定技术底子，它很好；想要有引导、跨平台覆盖，就看 Portmaster。

Safing Portmaster

官网 ↗原文

比普通防火墙更有野心：它监控并控制每个应用的活动，界面更友好，内置隐私功能，把门槛给非专家降下来。取舍是它比 simplewall 更重、更有主张，在低配机器上这份开销是真实的。想要应用级网络控制又带引导，它是强选；只要一个羽毛级拦截器的极简派会更喜欢 simplewall。

Plausible Analytics

官网 ↗原文

想要诚实的流量数字、又不想多一个项目要管，就选 Plausible。面板只有一页，脚本轻如羽毛，因为它不存个人数据也不存 IP 地址，同意横幅通常可以退休。诚实的短板是收费模式：托管方案是付费订阅，唯一的免费路线是自建社区版，那就要跑服务器。这个取舍是刻意的，一家付费公司没有理由去变现你的访客。看重简单和欧盟托管、也愿意付费或自建，选 Plausible。需要漏斗，就找更深的工具。

Auditor

官网 ↗原文

Auditor 做的是多数安全工具做不到的事：给出密码学证明，而不只是软件的声明，证明一台设备跑的是它声称的系统。利用安卓硬件支持的密钥库和验证启动链，它可以让一台安卓设备用二维码审计另一台，或做定时远程检查并邮件告警。短板是硬件支持窄：最好用跑 GrapheneOS 或原生安卓的 Pixel，而且只有你明白证明失败意味着什么，价值才落地。GrapheneOS 用户，它是补全信任模型的自然搭档。

ALTCHA

官网 ↗原文

ALTCHA 是这里的默认选择，因为它做垃圾防护时不把你的访客交给任何人：计算在访客浏览器里完成，校验在你的服务器上，关于他们的一切都不被记录。对站长来说，这意味着可以没有任何同意提示就放上去的验证码，因为没有追踪要同意。诚实的短板在于工作量证明是什么、不是什么。它让批量垃圾请求变贵，因为每个请求都要消耗算力，但挡不住专门针对你、也愿意付这个代价的攻击者。联系表单或注册，想止住洪水又不想盯住读者，选它。面对集中且资源充足的对手，要上分层防御。

MAT2

官网 ↗原文

普通文件里的元数据，照片里的 GPS 坐标、PDF 里的作者名、音频里的录音设备，是常规的隐私泄漏，多数人从不检查。MAT2 在很宽的格式范围上处理得干净，还直接集成进文件管理器 Nautilus 和 Dolphin，右键就能剥，不用开终端。开发已经安静，仓库现在已归档，所以把它当成稳定、已完成，而不是还在维护。Linux 用户它做得很好；Windows 和 Mac 用户需要 ExifTool 或其他替代。

Haven

官网 ↗原文

想法很巧，把一台闲置安卓手机变成运动、声音和光线传感器，看守一个房间或一台笔记本，对很具体的实体安全顾虑来说是对的工具。要知道它多年少有开发，所以把它当成稳定但静止的项目，而不是还在持续改进的东西。有旧手机、也有具体理由要盯住某个空间，它有用；别指望持续更新和打磨。

GoatCounter

官网 ↗原文

GoatCounter 是给博客作者或开源维护者的，只想知道人们读了什么，别的不要。它统计访问不用 cookie 也不用个人数据，自建几乎是最省事的分析方案，因为整个东西是一个 Go 二进制，没有一堆组件要拼。短板是这份专注的反面：功能刻意少，没有漏斗或深度分群，免费托管档只限非商业，商业站点需要付费方案或自建。个人站点或文档项目、一个干净的访问数就够的地方，选 GoatCounter。需要营销级报表，另找别处。

Matomo

官网 ↗原文

从 Google Analytics 迁出来、又不肯丢掉能力时，就选 Matomo。它覆盖营销团队期待的深度报表，同时把数据留在你控制的基础设施上，配置之后无 cookie 的追踪模式还能去掉同意横幅。这份能力也是短板：比极简的追踪器更重，即使在自己的服务器上，部分高级功能也在付费插件后面。真用得上那些深度、也托管得起，选 Matomo，新西兰的充分性认定还能缓解欧盟数据的问题。只读访问数，就选更轻的。

SecureDrop

官网 ↗原文

新闻机构接收线人材料的那套严肃、经过审计的标准，它对 Tor 的依赖是威胁模型里刻意的一部分，而不是要移除的障碍。诚实的现实是部署和正确运行都很重，面向有真实安全需求的组织而不是个人。你是要保护线人的发布者，这是参考工具；只是想安全传文件，它远超所需。

GlobaLeaks

官网 ↗原文

SecureDrop 更易接近的替代品，经过审计，设计上让较小的组织没有专门安全团队也能架起匿名举报通道。它仍跑在 Tor 上，仍要求你认真对待运维安全，所以是更容易，不是不费力。非政府组织、行动者或较小的媒体需要保护线人，它是强选；个人只想要简单的私密通信，另找别处。

AdGuard DNS

官网 ↗原文

进入 DNS 层广告与追踪拦截的轻松入口：把两个 IP 地址指过去，所有设备就都在过滤了，不需要装应用。与 NextDNS 相比，它的按设备定制不够细，想要详细配置的高阶用户可能更偏好另一个。想在几分钟内少折腾地把拦截跑起来、也接受托管服务处理你的查询，选 AdGuard DNS。深度可配置是优先项，就看 NextDNS 或自建方案。

mCaptcha

官网 ↗原文

mCaptcha 走的也是尊重隐私的路子，但明确瞄准洪水防护：不用访客的 IP 地址做限流，不建任何画像，所有校验都在你控制的基础设施上。已经自建、也熟悉命令行的站长，它轻量的 Rust 后端很合适。短板有两处。生态比大名字小，你要靠项目自己的文档；没有托管档，部署和维护都归你。自己管整套栈、想要零访客追踪的垃圾控制，选它。需要别人托管、贴进去就能用的组件，就跳过。

EFF

官网 ↗原文

它不是一款软件，而是电子前沿基金会的指南、工具与教程库，价值在于它是一个可信的起点而不是产品。局限也正在此：它只教和指路，不替你加密文件或拦追踪器。把它存成书签，作为学该做什么、该信哪些工具的地方；为教育而来，然后去装真正的工具。

Friendly Captcha

官网 ↗原文

想要隐私优先、无拼图的体验又不想自己起服务器，就选 Friendly Captcha。因为挑战是隐形的、在后台跑，访客从不停下来读扭曲的文字，你也不用请求追踪同意。它在欧盟，数据问题也就留在大西洋这一边，如果美国传输是你在意的点，这很要紧。诚实的短板是它专有且收费，代码不能查验也不能自建。想要省心、合规友好的组件、也接受账单，选它。开源或自己跑更重要，就选 ALTCHA 或 mCaptcha。

iMazing

官网 ↗原文

iMazing 填的是 MVT 的取证能力与运行它所需命令行技能之间的鸿沟。间谍软件分析功能免费，不需要技术背景，会引导你先建一台本地设备备份，再对已知指标做检测。取舍是 iMazing 是闭源商业软件：你信任一家私营公司的实现而不是审计代码，底层检测仍依赖与 MVT 相同的公开指标库。不懂技术的 iOS 用户想要一键做个体检，它是当下最容易上手的起点。

NextDNS

官网 ↗原文

真正强的网络层拦截器，比普通 DNS 过滤强的地方在控制：按设备配置文件、家长控制、分类拦截、可调的日志，全都不必在每台设备上装东西。诚实的提醒是它是云服务，你把查询托付给 NextDNS，免费档有每月查询上限，超过要付费。想给整个家庭设好就不管的人，这个取舍合理。要零第三方参与，就自建 Pi-hole。
