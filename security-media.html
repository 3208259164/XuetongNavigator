视频与音频13

OpenCut

官网 ↗原文

它的说法简单而且成立：CapCut 式的剪辑，却不把原始素材和使用习惯交给字节跳动。诚实的短板是年轻、有些地方粗糙，与成熟的桌面编辑器相比会缺功能、偶尔卡壳。想要快速做社媒短视频、什么都不用装、什么也不离开浏览器，选 OpenCut。今天就需要深度特效或真正的调色，先用 Kdenlive 上手，等 OpenCut 长大再看。

Shotcut

官网 ↗原文

Shotcut 位于简单与专业之间：比入门玩具强，比 Kdenlive 少些杂乱。素材来自不同来源时，原生多格式时间线真能省时间，在普通硬件上也跑得动。弱点是界面，停靠面板式布局看着旧，要摆弄一阵才顺手。想要真剪辑能力、又不想爬最陡的坡，它是个扎实的选择，而且干活完全不需要联网。

Kdenlive

官网 ↗原文

当你已经超出手机剪辑应用、想要真正的控制又不想给 Adobe 付钱，就用 Kdenlive。它支持代理剪辑、调色和数百种特效，稳定开发了十多年。取舍是学习曲线：界面密集，第一天会让人觉得压人。经常剪辑、想要一个能随你成长的工具，值得熬过去。

OpenShot

官网 ↗原文

OpenShot 是开源剪辑器里最温和的入口，而这正是它的意义：如果你的参照是 CapCut 或 iMovie，几分钟就会觉得熟悉。这份简单的代价是稳定性。它长期有名声说在较重项目上容易绊倒，所以要勤保存，别指望它扛长而复杂的剪辑。短片和第一次剪辑的好起点，时间线一有野心就会让人烦，那时就该升到 Shotcut 或 Kdenlive。

Ardour

官网 ↗原文

剪个播客用 Ardour 过头，做一张唱片则刚刚好。它是真正的数字音频工作站，深度能与商业工具相比，项目从 2000 年代初持续开发至今。这份深度同样是警告：它是这一类里最陡的学习曲线，并且默认你已经懂音频路由和信号流。做音乐或认真的多轨工作，选 Ardour。快速剪辑和清理，Tenacity 是更理智的起点。

Tenacity

官网 ↗原文

Tenacity 存在的理由只有一个，而且是好理由：去掉让人不安的部分之后的 Audacity，也就是遥测，以及易主之后到来的新条款。功能上它就是熟悉的 Audacity，用过的人马上就能上手。短板是势头，志愿分叉比有资金的原始项目走得慢，发布可能不频繁。想要一个不往外报数据的纯粹本地音频编辑器，它干净合适。重度音乐制作，Ardour 是更大的工具。

VLC Media Player

官网 ↗原文

来自非营利组织 VideoLAN 的免费跨平台播放器，本地几乎能播放所有音视频格式，没有广告、追踪或遥测。功能与设置很多，界面上手初期可能不太好用。

AntennaPod

官网 ↗原文

安卓上的开源播客管理器，可订阅任意 RSS 源，支持离线下载、变速播放，可选 gpodder.net 或 Nextcloud 同步。不含广告和追踪，但只做安卓，没有 iOS 和桌面版。

FlowBlade

官网 ↗原文

多轨非线性视频编辑器，界面简单。

Cinelerra GG Infinity

官网 ↗原文

简单的视频编辑器，可做转场、特效、字幕，以及片段拼接。

VitCutter

官网 ↗原文

基于 Python 的跨平台小工具，用来剪切和拼接视频。

Natron

官网 ↗原文

免费开源的桌面节点式视频合成软件，功能接近 After Effects。支持灵活的转描、二维与平面跟踪、抠像工具、曲线与偏移编辑器、GPU 与网络渲染，还能通过社区插件或 Python 脚本扩展。

Audacity

官网 ↗原文

桌面端易用的多轨音频编辑器与录音工具，Adobe Audition 的免费替代。可从真实与虚拟设备录音，导入导出多种格式，具备高质量处理、进阶多轨编辑、降噪、音高校正、音频修复等能力，可通过社区插件扩展，也支持自定义宏和多种脚本。

流媒体5

Open Video Downloader

官网 ↗原文

给 yt-dlp 引擎套了个友好的图形界面，意味着不用碰命令行就能从大量站点取视频。现实的提醒是下载器永远在追站点变化，所以偶尔源失效、需要更新是这份活的一部分。想要 yt-dlp 的能力又不想开终端，它是个好选择；命令行用户直接跑引擎就行。

PeerTube

官网 ↗原文

对中心化视频的联邦式、可自建答案，点对点播放分摊带宽，让小实例也能扛住一个热门视频。这份联邦也是短板：没有统一的搜尽一切的前门，发现是分散在各实例之间的，内容也参差。想拥有自己视频托管空间的创作者和社群，它是最强选择；只想逛一个庞大的统一库，则不太方便。

DTube

官网 ↗原文

与区块链基础设施绑定的去中心化视频平台，定位成主流站点抗审查的替代。预期要摆正：受众小，体验比在位者粗糙，加密集成塑造了整个平台。专想要基于区块链、难以被去平台化的视频，可以一看；不是主流流媒体服务的日常实用替代。

Odysee

官网 ↗原文

建在 LBRY 之上的去中心化、区块链支撑的视频平台，主要用处是给创作者一个比主流站点更难被去平台化的发布地。诚实的取舍是去中心化带来参差的内容质量和更小的受众，加密打赏那层也不是人人有感。想要韧性和所有权的创作者，它是个合理的第二家园；不是大流媒体站点在目录或打磨上的对等替代。

OBS Studio

官网 ↗原文

强大的桌面直播与录屏软件，免费开源。具备实时音视频采集、场景合成、编码、录制与推流，支持格式广，可用社区插件扩展。

RSS 阅读器8

Miniflux

官网 ↗原文

Miniflux 刻意有主张：没有分类、没有星标、没有杂物。想要一个快、少维护、完全由你掌控的阅读器，它接近理想。Go 单文件加 Postgres 的栈好维护，兼容 Fever 与 Google Reader API，意味着能配上你已经在用的任何手机应用。诚实的短板是自建在这里是真要求，不是可勾选选项。有托管方案，但这个工具的全部吸引力在于数据归你。习惯 VPS 的开发者会如鱼得水。

Feeder

官网 ↗原文

Feeder 是安卓上省心的 RSS 选择：开源、在 F-Droid 上，直接在设备上读订阅，不需要账号，也没有同步服务盯着你读什么。它只做安卓，刻意简单，别指望跨平台同步或功能堆满的高阶阅读器。安卓用户想要一个私密、不要账号的订阅阅读器、别的都不要，它把这件事做得好。

NetNewsWire

官网 ↗原文

在苹果设备上想要订阅私密又免费，就选 NetNewsWire：开源、没有广告和追踪，直接读订阅，不把阅读习惯经由某家公司的服务器。局限就在吸引力里，只做 Mac 和 iOS，跨平台家庭得另找。苹果生态里想要干净、无杂物、尊重用户的阅读器，它显然是首选。

Newsboat

官网 ↗原文

Newsboat 赢得的是那部分整天待在终端、希望订阅阅读器像文本编辑器一样工作的用户。Vim 键位、可脚本化的过滤语言、能把文章管道给任何外部程序，对自动化和自定义工作流确实强大。它不适合所有人：没有图形界面、没有同步、没有手机端，你就在运行阅读器的那台机器上读。按季度发布、签名压缩包，是有维护的项目的信号。终端本来就是你的家，它就是显然的选择。

Akregator

官网 ↗原文

KDE Plasma 用户想要原生订阅阅读器、又不想在桌面环境之外装东西，Akregator 是自然之选。它处理大量订阅表现好，与其他 Kontact 应用集成干净，不需要账号或云服务。取舍是界面比更新的 GTK 或网页阅读器显老，跨设备同步订阅这类进阶功能也没有。作为纯本地桌面阅读器，最适合已经在 KDE 生态里的人。6.4 起也可用于 Windows。

Feedbro

官网 ↗原文

Feedbro 是浏览器扩展式的订阅阅读器，订阅留在浏览器本地而不是经由某服务同步，这就是它的隐私角度。代价是闭源，那份隐私说法你只能信；绑在浏览器上也意味着订阅不跟到手机。适合桌面只用一个浏览器、想把阅读留在外部服务器之外的人；想要开源代码或手机同步的，另找别处。

NewsFlash

官网 ↗原文

NewsFlash 是 GNOME 桌面上打磨最好的订阅前端，已经在跑自建订阅服务的人是自然的搭配。设计干净，全程键盘可用，自适应布局能缩到小屏。需要提前知道的局限是它主要是同步客户端，不是独立阅读器。没有现成的订阅服务账号，得先自己搭一个。只做 Linux，明确面向 GNOME 用户，不过在别的 GTK 桌面上也能正常运行。

Tiny RSS

官网 ↗原文

基于网页的新闻订阅阅读与聚合器，支持 RSS 和 Atom。免费开源，平台可定制、可自建，用来管理你的订阅源。

翻译工具7

LibreTranslate

官网 ↗原文

这一组里唯一完全可自建的机器学习翻译器，意味着用自己的实例，任何文本都不碰专有服务，这是真实的隐私收益。诚实的取舍是质量：它的开源模型在细腻程度上比不过 DeepL 或谷歌，对不常见语言尤其明显。独立、不把文本漏给第三方优先于精致，而且你能跑起服务，选 LibreTranslate。最看重翻译准确、隐私次要，就不是它。

Linguist

官网 ↗原文

比常见的翻译扩展更有野心，支持设备端离线翻译，还能指向你自己的翻译后端，这确实少见。这份灵活的代价是配置：让离线模型或自建服务跑起来，比一键装个插件费事。想让翻译完全留在自己机器上、也愿意配置，选 Linguist。只想无脑快速翻一页，更轻的前端更快到手。

SimplyTranslate Mobile

官网 ↗原文

值得注意的是跨网络触达，有明网、Onion、I2P 和 Lokinet 实例可选，适合已经在通过这些层路由流量的人。项目偏小、开发安静，和其他前端一样靠你选的实例访问公共服务。想要一个极简、能和 Tor 或 I2P 配合的安卓翻译器，选它。想要打磨好、活跃开发的，先把预期放低。

Lingva Translate

官网 ↗原文

巧妙的前端，取谷歌翻译的质量又去掉谷歌的追踪，结果好用而不被画像。诚实的提醒是开发已安静下来，而且它依赖一个自己并不控制的公共服务，公共实例因此脆弱。最好自建，代理归你，不必指望别人的实例一直在线。想要谷歌级翻译又保持私密、且能自己托管，选它；共享实例当成尽力而为。

TranslateLocally

官网 ↗原文

在本机跑翻译模型是真正的隐私保证，而不是政策承诺：文本从不离开你的设备，就不可能被记录或开采。Bergamot 引擎在它覆盖的语言上质量站得住，尤其欧洲语言对。短板是覆盖：模型库比云服务窄，经常在不那么通用的语言之间翻译，会遇到空缺。翻译敏感文档、不能接受文本离开自己机器的人，以及想要本地翻译 API 的隐私意识开发者，它是对的工具。

DeepL Translate

官网 ↗原文

注意条目里写着的警告：免费版会用你的文本训练，只有付费的 Pro 版才真正让译文保持私密。DeepL 的质量确实是同类最好，这是考虑它的真正理由。所以结论很清楚：翻译准确很重要、也能让敏感文本走 Pro，就付费；永远别把机密内容粘进免费版。付不起，自建方案比免费 DeepL 更能保护你。

LanguageTool

官网 ↗原文

Grammarly 的正经开源答案，杀手级功能是能自建服务端，让你的文字永不离开自己的网络，这正是 Grammarly 给不了的。取舍是免费托管档检查更短的文本，进阶建议会把你推向订阅。隐私意识的写作者思路很清楚：文本敏感就自建引擎，日常小修就用免费插件。不想把每个句子喂给美国云，就用它代替 Grammarly。

地图4

Organic Maps

官网 ↗原文

多数离开 Google 地图的人，推荐 Organic Maps：完全离线、免费、开源、无广告、无追踪，界面干净不跟你较劲。这份简单的代价是路线规划和实时数据不如谷歌丰富，所以它更适合徒步、骑行和旅行，而不是依赖实时路况的城市驾驶。日常的私密导航要好用，它正好命中。

OsmAnd

官网 ↗原文

OsmAnd 是高阶用户的离线地图：下载整个区域，没有数据连接也能导航，叠加的细节和设置远多于那些更友好的应用，全程没有谷歌盯着路线。这份深度也是成本，界面繁杂，学习曲线真实，免费版限制地图下载量。想要认真的离线导航和自定义、也愿意爬坡，选它；随意的用户会更喜欢简单些的。

OpenStreetMap

官网 ↗原文

OpenStreetMap 是整个这一类的地基：免费、开放许可的世界地图，与谷歌地图不同，它没有商业动机去记录你在看哪里。作为网站它更像数据源和参考地图，而不是逐向导航应用，所以多数人实际是通过建在它之上的应用来用。支持它、拿它当地基层；日常导航用 OsmAnd 或 Organic Maps。

CoMaps

官网 ↗原文

CoMaps 接着 Organic Maps 往下走，治理模型让移除联盟追踪成为结构性的事，而不是一次性的决定。基于 OpenStreetMap 数据的离线优先导航，正常使用中位置数据不碰任何第三方服务器。所有 OSM 系应用共有的取舍在这里照旧：地图完整度取决于贡献者密度，乡村或测绘少的地区会有谷歌地图能补上的空缺。城市导航、以及测绘完善的地区徒步骑行路线，CoMaps 是个不问你要位置数据的强隐私默认。

照片存储5

Immich

官网 ↗原文

Immich 已成为自建照片管理的事实推荐，理由充分：界面接近 Google Photos，迁移感觉自然，FUTO 的支持给了它开源媒体项目少见的财务稳定。隐私模型很直白：你的服务器、你的数据、没有第三方。一条重要的实话：Immich 不是端到端加密。文件以可读形式存在你的服务器上，照片的安全取决于你把主机和网络访问守得多好。愿意跑家用服务器或 VPS 的人，用这个换回对照片库的控制，是合理的交易。

Ente

官网 ↗原文

Ente 是那个不需要你妥协的照片存储推荐：端到端加密、开源、安卓和 iOS 上都有真正的跨平台应用，这在这个领域很少见。你把加密数据块托付给它的服务器，但密钥始终在你手里，不想信任任何人也有自建路径。对多数想找一个真能日常用的私密 Google Photos 替代品的人来说，选它。关于司法管辖：Ente 在印度班加罗尔构建和运营，美国注册的实体只是特拉华州的控股公司，所以我们按印度列，团队和工程实际所在的地方。

PhotoPrism

官网 ↗原文

PhotoPrism 是给想彻底拥有自己照片库的人：自建，自动标签和搜索强到能和云巨头比，而且没有月费。诚实的短板是自建就是全部工作，服务器要你提供并守住，目前也没有交钥匙的托管选项，所以这里的隐私等于责任。已经在跑家用服务器或 NAS、想把照片完全从别人的云上拿开，选它。

Piwigo

官网 ↗原文

Piwigo 是老资格的照片图库平台，吸引点在灵活：自建求完全控制，或不想折腾就用它的托管，内置像样的用户管理。在现代顺滑应用旁边它显老，手机体验偏实用而谈不上愉悦。想要成熟、可自建、共享控制细致的图库，也不介意更老派的界面，它值得。

Internxt Photos

官网 ↗原文

Internxt 照片在云端照片存储的隐私基本功上是齐的：零知识加密，免费档可试，还有让厌倦永久订阅的人心动的终身方案。作为较年轻的西班牙服务，它的履历更短，应用也不如它竞争的巨头成熟，把这些和价格一起权衡。想要欧盟管辖下的加密照片备份、又被打动于终身定价，它是个公平的选择。
