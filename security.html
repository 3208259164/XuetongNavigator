即时通讯8

Jitsi Meet

官网 ↗原文

不用注册账号、发个链接就能开始说话，视频会议里最省事的做法；自建则整条技术栈都由你掌控。对加密要心里有数：常规多方通话走的是媒体服务器，端到端模式是另一个更受限的设置。临时起意的会议和自建者都适合；如果这次通话确实敏感，记得确认端到端加密是否真的开着。

SimpleX Chat

官网 ↗原文

去中心化即时通讯，不给用户分配任何标识（连随机编号都没有）。通过一次性邀请链接或二维码建立联系人，所有数据只存在本机。

Signal

官网 ↗原文

界面和用法接近 WhatsApp 等常见应用，迁移成本低。注册需要手机号作为身份标识。端到端加密开源通讯。

Stoat

官网 ↗原文

开源、可自托管的 Discord 替代品，原名 Revolt。面向想离开 Discord 的社群，但消息不是端到端加密的。

Session

官网 ↗原文

注册不需要手机号，也不需要邮箱，这是它最大的卖点，对注重隐私的人来说确实重要。代价在覆盖面上：你认识的人几乎都没在用，把联系人加进来要靠一串账号 ID 而不是熟悉的用户名，这活儿不轻松。把抗元数据收集排在便利之前、也愿意做那个到处推荐它的人，可以选 Session；只是想和朋友安全聊天，Signal 走得更快更远。

Delta Chat

官网 ↗原文

借用现有的电子邮件网络、不自己搭服务器，是个聪明的办法：只要有邮箱地址就能联系上，也不需要另外注册什么。代价是从邮件沿用下来的：发件人、收件人和发送时间这些元数据，即使正文加密了，也像电子邮件一贯那样会泄露出去。想联系已经在那套基础设施上的人，它很合适；如果担心的是流量分析，它就不是答案。

Molly

官网 ↗原文

Signal 的安卓加固分支，增加了加密本地数据库、锁屏时自动擦除内存，并通过 Orbot 支持 Tor 与 SOCKS 代理。提供两个版本：带 FCM 推送的，和完全不含谷歌组件的纯自由软件版。

Tox

官网 ↗原文

功能覆盖较广，但协议仍高度实验性，使用需谨慎。

邮件客户端9

K-9 Mail

官网 ↗原文

手上账号多、又常在安卓上泡邮箱，K-9 Mail 处理大流量的表现比那些打磨得精致的消费级客户端更好，开源，也有多年历史可查。它本身不是隐私邮箱服务商，只是个客户端，隐私仍取决于你连的是哪台服务器。界面看得出年代，也要花点时间上手；只想要好看好用的，可以看它的后继者 Thunderbird for Android。

FairEmail

官网 ↗原文

FairEmail 是目前安卓上对隐私最较真的邮件客户端：主动屏蔽追踪像素、剥离不安全的 HTML，并且拒绝 Firebase 云消息推送，改用纯粹的 IMAP IDLE。免费版已覆盖所有必需功能，过滤规则、S/MIME 签名、定时发送等进阶功能用一次性内购解锁，不是订阅制。代价是配置复杂：快速设置向导只覆盖常见服务商，稍冷门的必须手动配 IMAP。想用真邮件而不是网页版套壳的安卓用户，选它。

NeoMutt

官网 ↗原文

NeoMutt 是终端邮件客户端的首选，适合要最大控制权、不要图形界面开销的人：整个程序跑在终端里，与 GnuPG 的 OpenPGP 集成干净，配 Notmuch 能在大量邮件里做快速全文检索。配置文件本身当脚本用，高阶用户几乎什么都能自动化。实话说的短板是入门曲线陡，纯文本界面是有意的取舍，不是缺陷。需要手机客户端或拖拽附件就别选；它适合开发者、系统管理员和整天待在终端里的隐私意识用户。

Mailvelope

官网 ↗原文

Mailvelope 把 OpenPGP 直接装进 Gmail、Outlook 这类网页邮箱，在浏览器里就能用，这既是它的全部吸引力，也是全部局限。它只保护邮件内容，不保护元数据，收发双方都要配好密钥，所以繁琐，私密程度也只取决于你写给谁。卡在主流的网页邮箱账号上、又必须给某些邮件做真正的端到端加密时用它；不要把它误当成换了隐私服务商。

Canary Mail

官网 ↗原文

Canary Mail 是这一组里打磨得不错的付费手机客户端，内置 PGP，界面不像 2009 年的老古董。代价是加密引擎那部分是开源的，而应用大部分不是，你是在为一个闭源客户端、而不是一个开放标准付钱。适合 iOS 和安卓上希望加密用起来轻松、也愿意信任一家商业公司把它做好的人。

GNOME Evolution

官网 ↗原文

对用 GNOME 桌面、想要一套完整个人信息管理而不愿东拼西凑的人来说，Evolution 是自然之选：邮件、日历、通讯录共用同一层数据，收件箱里的会议邀请会直接落进日历。原生支持 OpenPGP，不需要 Enigmail 这类绕法。缺点是界面显老，Exchange/EWS 连接器是单独的包，而且它严格只做 Linux 应用，没有手机端和 Windows 版。最适合已经习惯桌面的 GNOME 用户，需要一个集成、尊重隐私的 Outlook 替代品。

Kontact

官网 ↗原文

Kontact 是 KDE 这边的 GNOME Evolution：一套完全集成的 Linux 个人信息管理，各组件（KMail、KOrganizer、KAddressBook）也能单独运行，比乍看之下灵活。OpenPGP 与 S/MIME 内置，CalDAV/CardDAV 同步开箱可用，Akonadi 后端处理大容量邮箱时不会卡住界面。诚实的短板是 Akonadi 属重量级依赖，配置费劲，偶尔还要手动重置数据库。适合 KDE Plasma 用户，想要一个尊重隐私的 Outlook 替代，而不是极简客户端。

Thunderbird

官网 ↗原文

想把自己邮件留在本地、在不信任网页邮箱的前提下加上 PGP，桌面端就选 Thunderbird，免费，背后有 Mozilla。但要弄清它的身份：客户端，不是服务商，隐私跟随你所连的账号，它本身不施什么魔法。界面感觉旧，配置要有耐心；不过在真正的电脑上集中管理多个账号，比它更灵活的不多。

Apple Mail

官网 ↗原文

Apple Mail 能进这个名单，主要靠邮件隐私保护功能：它把远程图片的加载转到苹果服务器，发件人无法确认你的 IP 和打开时间，零配置就生效，是对抗邮件追踪的一项实在防御。在 macOS 上还能通过第三方 GPG Suite 插件支持 OpenPGP，企业用途的 S/MIME 也内置。诚实的短板是应用闭源、与苹果生态绑得很紧：装不到苹果硬件之外，邮件隐私保护怎么实现没有独立审计，进阶隐私设置也比专门的开源客户端浅。想要合理默认、又不想换应用的苹果用户，可以选它。

邮箱服务8

ProtonMail

官网 ↗原文

Proton 的免费版是这里最实在的入门口，因为真正的端到端与零访问加密不用先付费就能用，瑞士司法管辖也是实打实的加分。摩擦在于：Proton 用户之间加密是自动的，发给外部就得用密码或 PGP，IMAP 还要在付费方案上用 Bridge 应用。想要成熟、经过审计、各平台都有应用的服务商，也接受它围墙花园的模式，就选它。Proton 会删掉十二个月未登录的免费账号，付费账号豁免，删前会先警告，提醒邮件从删除前一个月开始发。关键在地址：被删掉的 Proton 地址通常找不回来，也不能重新分配给任何人，包括你，所以一个闲置的免费地址基本就是永久消失。每年登录一次，并设一个备用邮箱，让警告真能送到你手上。

SimpleLogin

官网 ↗原文

SimpleLogin 不是邮箱，而是别名转发器：可以给每个网站派一个不同地址，真实收件箱始终藏着，回信也从别名发出，没人知道你真正的地址。它现在归 Proton 所有，往好里说是让人放心，往坏里说是把鸡蛋放进同一个篮子。把它当作叠在现有邮箱上的一层，而不是替代品。

addy.io

官网 ↗原文

addy.io 在基于别名的收件箱防护里位置很好：免费版是真有用，标准别名不限量、不要信用卡，浏览器扩展让随手建别名毫无阻力，GPG 加密让转发中的邮件也保持私密。短板是免费方案每月 10MB 流量上限，如果你转订阅邮件，这个额度紧到会碍事。用得狠的人会发现付费档价格还算合理。刚离开 Gmail 或 Outlook 的人，作为第一个别名服务挺扎实。

Forward Email

官网 ↗原文

它最突出的特点是透明：处理你邮件的代码就是跑在他们服务器上的同一份代码，没有专有黑箱要你盲信。Cure53 做的首次独立安全审计已于 2026 年公布。自有域名可免费用别名转发，付费方案解锁支持 IMAP 的完整邮箱。选择美国服务商的代价是美国法律管辖适用，与瑞士或德国的替代者相比这是要真考虑的。自建能完全抹掉这层顾虑，代价是你要自己管邮件服务器。

Disroot

官网 ↗原文

Disroot 是志愿者运营、靠捐赠维持的集体项目，这一点决定了全部：免费方案带自定义域名和一整套服务，但支持与在线率靠的是善意，不是付费的服务等级保证。这让它很适合认同其行动主义、反企业气质的人，对需要保证重要邮件稳定可达的人则有风险。把它当成你加入的社区项目，而不是你买的产品。

mailbox.org

官网 ↗原文

Mailbox.org 是那种好意义上的无聊德国选项：付费、对商业友好、支持自定义域名和加密，从 2014 年起就安静地把活干好。没有免费方案，界面也拿不到设计奖，所以它适合看重德国强隐私法下的稳定服务商、而不是花哨功能的人。想要一个和 Thunderbird 配合良好的可靠收件箱，也乐意每月付几欧元，它值得占这个位置。

Posteo

官网 ↗原文

每月 1 欧元，Posteo 是最便宜的一批独立邮件服务商之一，而且隐私靠的是设计而不是营销口号。信箱存储加密、网页端可管 PGP 密钥，还支持把现金装进信封寄去付款，对想要这种匿名性的人是真匿名。诚实的局限：它是传统托管服务商，不是零知识，除非你用自设口令开启信箱加密，否则 Posteo 理论上可能被强制调取静态邮件。对多数想彻底离开广告驱动邮箱的人来说，这个取舍完全合理。

StartMail

官网 ↗原文

StartMail 出自 Startpage 团队，是稳妥、不折腾的付费邮箱，别名不限量、支持自有域名，算得上真正能替代 Gmail 的东西而不是玩具。短板是价格：没有免费档，你得付钱才能离开那个免费但被开采的收件箱。想要一个荷兰托管、能与 Thunderbird 配合的账号，也已经接受隐私邮件就是要花钱，就选它。

云存储9

Nextcloud

官网 ↗原文

当真正的目标是拥有自己的基础设施、而不是向厂商租隐私时，这是正确答案，规模可以从树莓派一路长到公司服务器。代价是你成了管理员：安装、更新、备份、安全都归你，这是实打实的承诺，不是下载完就完事。自建对你有吸引力、你也会维护，就选它；想要别人替你跑着的存储，托管服务是更省心的路。

Proton Drive

官网 ↗原文

来自 Proton 生态，如果你已在用他们的邮件或 VPN，想要同一把瑞士伞、同一个账号下的加密存储，这是自然之选。诚实的局限是它比 Proton 其他产品年轻，桌面端和同步客户端一直在追赶，免费的 15GB 也不算多。想把自己收拢进 Proton，它很强；若单纯按功能衡量一个独立网盘，更成熟的选项竞争力很足。

Internxt Drive

官网 ↗原文

较年轻的存储服务，MIT 许可，零知识加密，免费 1GB 长期可用，另有经过审计的方案和终身方案，这种组合不常见。实话说它比成熟玩家小也新，生态和客户端成熟度还在追赶。想要开放、加密的存储，又觉得终身定价划算，它是个公平的选择；需要深厚、久经考验的应用生态，就把它的年龄一并算进去。

Filen

官网 ↗原文

德国服务，客户端加密，免费 10GB 相当大方，流量不限，这个搭配不错。诚实的缺口是没有公开仓库可供检查，规模也小，所以你更多是在信任它的实现而不是验证它。想要放在欧盟的加密存储、还能免费试用，它是个不错选项；老牌名字会显得更有把握。

Infomaniak kDrive

官网 ↗原文

kDrive 的长处是瑞士司法管辖加上真能用的产品：桌面同步客户端、手机应用、浏览器内办公编辑，数据不经过美国或欧盟的云服务商。普通文件在静态和传输中都加密，但默认不是零知识，所以 Infomaniak 在被强制时能访问。Vault 功能为敏感文件提供真正的客户端零知识加密，但要手动开启，不是默认体验。想要一个不用自建的 Google Drive 替代品，kDrive 是稳妥之选，前提是你明白完整的零知识得用 Vault，而不是主盘。

iCloud

官网 ↗原文

开启高级数据保护后，iCloud 对大部分数据变成端到端加密，这一点领先于谷歌和微软的默认做法。短板也很实在：这层保护默认关着，要你自己打开；代码闭源，你信的是苹果的说法；公司受美国管辖。已经身处苹果生态、也会把 ADP 打开的人，选它合理。想要可审计的零信任存储，专门的加密服务商更强。

MEGA

官网 ↗原文

免费 20GB 是明显的吸引力，加密在客户端完成，理论上托管方读不到你的文件。诚实的提醒是免费方案有每日流量限制，同步大量数据就会被卡；MEGA 的过往也让一些人不太愿意把最敏感的资料交给它。作为大容量的免费通用网盘不错；把最大信任放在第一位的话，另选别家。

Tresorit

官网 ↗原文

Tresorit 站得住的地方是真正重要的那项：加密是真的，审计可信，安永、Computest、TÜV 莱茵的 ISO/IEC 27001 都在列，瑞士邮政持股意味着它在瑞士而非欧盟或美国法律下运营。短板是价格：属这一类里较贵的，客户端闭源，所以你信的是审计结论而不是自己查看代码。想要打磨好、商用级、有可核查审计记录、不用自己动手的加密云盘，选它。

NordLocker

官网 ↗原文

Nord 家族的加密存储，方案直白，500GB 与 2TB 两档，30 天退款期，冲着想要开箱即用的人去。值得点明的取舍是闭源，你信任的是公司的实现而不是自己验证。看重打磨好、有支持的产品胜过开源代码的人，它合理；把开源可验证当作硬要求，它就不是你的工具。

笔记与知识库9

Logseq

官网 ↗原文

先看清条款：Logseq 不加密，笔记是磁盘上的纯文本文件，所以它防的是窥探你的云服务商，防不了能碰到你机器的人。它的长处是作为本地优先的大纲工具与知识库，建立在完全属于你的文件上，没有锁定。目标是拥有数据、不落入 SaaS 孤岛，而不是防设备层面的入侵，就选它。需要真正的静态加密，这一类里它就不合适。

Joplin

官网 ↗原文

极受欢迎，5.5 万星，是 Markdown 笔记里事实上的开源选择，特殊优势是同步由你自带：Dropbox、Nextcloud 或随便什么，而不是被绑在一家厂商。短板是端到端加密要手动开启，配置比打磨过的商业应用更动手，新手容易绊住。想完全掌控笔记存在哪里、也不介意自己配同步，选 Joplin。想让笔记加密地自动出现、完全不用配置的人，该选托管服务。

Memos

官网 ↗原文

想要一个快速、零摩擦、又不喂给云服务的地方记下想法，Memos 在简单这一点上很难被超越。Go 单文件二进制内嵌 SQLite，一条命令就能起，MIT 许可意味着整套栈完全属于你。短板要说清楚：它不是加密笔记。服务器一旦被攻破，你的笔记就是明文可读。所以它对已经在跑加固基础设施的自建者是强选，对需要保密承诺却不想管自己安全边界的人则不合适。

Notesnook

官网 ↗原文

开发者开源代码之后，它现在是完全开源的了，这抹掉了过去最大的反对理由，不过巴基斯坦的司法管辖对某些威胁模型仍是问题。免费档相当大方，加密是端到端的，与 Standard Notes 正面竞争。想要富文本编辑器、能从其他应用轻松导入、第一天就不用付钱，选 Notesnook。与 Standard Notes 相比，它的审计历史更短，如果这是你的优先项，就把成熟度一并权衡。

Standard Notes

官网 ↗原文

经过审计、AGPL 授权，正是这一类该奖励的组合，对想要可验证端到端加密笔记的人，它是更稳的选择。诚实的短板是免费档故意只给纯文本：大家真正想要的功能，比如富文本和附件，都放在订阅后面。长期信任、美国团队、有审计的代码库比花哨编辑器更重要时选它，也要接受你大概会付费让它日常好用。

Cryptee

官网 ↗原文

总部在爱沙尼亚，加密在客户端完成，所以 Cryptee 确实读不到你的文档，它还能管照片，多数同类做不到。限制也实在：免费档只有 100MB，项目小、没有公开代码可查，所以你更是在信任一个半封闭的服务，而不是审计过的开源项目。想在同一个地方同时要加密文档和私密照片存储、也愿意过了免费额度就付费，它合适。笔记量大又要开源代码的，看 Standard Notes。

Turtl

官网 ↗原文

开发明显慢了下来，免费上限 50MB，体量又小，Turtl 更像一个过了高峰的项目，而不是能把日常笔记押上去的东西。它的定位是带端到端加密和简单分享的书签与笔记，需求不高的话仍可用。说实话，Standard Notes 和 Notesnook 都更活跃，今天选 Turtl 的主要理由只剩它的具体布局本来就合你意。否则从更活跃的选项起步。

Anytype

官网 ↗原文

它的架构与云优先的工具确实不同：保险库在你的设备上，同步可选且加密，即使被强制，公司也读不到你的内容。这是 Notion、Evernote 以及多数托管替代品给不了的隐私保证。诚实的短板在许可：应用是源码可见而不是开源，对客户端代码的独立安全审计有限。想要完全开源栈的自建者，Memos 或 Joplin 更合适；其他想要 Notion 级能力又有真实隐私默认的人，Anytype 是现有最可信的选项。

Org-mode

官网 ↗原文

Org-mode 是这一类里的高手上限：笔记是你完全拥有的纯文本文件，可以用 GPG 加密单条或整份文件，用 git 给所有内容做版本管理，从不碰不属于你的服务器。诚实的短板是它需要 Emacs，学习曲线陡，而且除了手机端第三方工具和其他编辑器插件，完整功能只在 Emacs 内可用。想要最大程度主宰笔记的技术型用户，没有别的能接近它。

它是 TrueCrypt 的延续，至今仍是全盘加密与加密容器的参照工具，还有隐藏卷这一手，用来应付需要否认得了的场合。麻烦在于它复杂且不留情面：忘了密码，或者系统加密中途出错，可能就永久锁死了。适合那些会认真读文档、要给磁盘和分区加密的人；只想保护几个文件，则属杀鸡用牛刀。

GnuPG

Kryptor

官网 ↗原文

免费开源的文件加密与签名命令行工具，支持 Windows、Linux、macOS。通过 libsodium 使用 XChaCha20-Poly1305、Argon2id、Ed25519 等现代算法，无配置项，可选加密文件名。

BitLocker

官网 ↗原文

Windows 专业版、企业版和教育版内置的全盘加密功能。使用 AES-XTS 加密系统盘和固定数据盘，可选由 TPM 支持的启动前认证。

密码管理器8

KeePassXC

官网 ↗原文

离线、不上云、不要账号、不订阅，密码就放在一个完全由你掌握的数据库文件里。这种所有权是双向的：备份要你自己负责，弄丢了也是你自己的事。它适合本来就有备份习惯的人，会让那些希望换个新手机密码就自动出现的人受不了。安卓端是另一个应用 KeePassDX，不是官方顺滑接续。把本地掌控看得比便利更重，选它。

Bitwarden

官网 ↗原文

这是第一选择，理由很简单：开源、经过审计、个人使用免费，各平台都能跑，不必在便利与信任之间二选一。实话实说的前提是，用官方云端意味着你的加密密码库放在别人的服务器上；介意的话可以自建。对大多数想摆脱浏览器自带密码管理的人来说，第一个该装的就是它，不用附加条件。

LessPass

如果喜欢 Bitwarden 但不想同步或存储密码，LessPass 是另一种思路：按主密码和站点信息现场算出密码，不保存任何数据。支持浏览器、手机和命令行。

KeePassium

面向 iOS 与 macOS 的 KeePass 兼容密码管理器，支持生物识别解锁、密码自动填充、与 iCloud 云盘等自动同步，读写全部 KeePass 数据库格式。

gopass

用 Go 编写的开源命令行密码管理器，兼容 Unix pass 的存储格式。凭据用 GPG 或 age 加密并纳入 git 版本管理，提供 Linux、macOS、Windows 安装包。

1Password

面向个人、家庭和团队的商业密码管理器，支持 Windows、macOS、Linux、安卓、iOS 及主流浏览器。采用双密钥架构，把主密码与本机生成的 Secret Key 结合使用。

Whonix

免费开源的桌面操作系统，强制所有流量经由 Tor 传输，由两台相互隔离的虚拟机组成（网关机与工作站）。

Qubes OS

Qubes 把靠隔离保证安全推到极致，把各项活动放在彼此隔离的虚拟机里，一台被攻破也够不到其他。这确实强，也确实苛刻：需要够好的硬件、真实的学习曲线和耐心，所以它明确是给专家用的。如果你是高风险用户、愿意投入这份功夫，少有比它更严谨的；其他所有人只会觉得阻力超过自己的威胁模型所需。

Arch Linux

官网 ↗原文

极简的滚动更新发行版，遵循自己动手的哲学：从最基础的系统开始，逐个选择组件自建，用 pacman 持续更新。

Fedora Workstation

官网 ↗原文

从 Windows 或 macOS 转过来，想要一个现代、维护良好又不用时时照看的 Linux，Fedora Workstation 是稳妥的默认选择；它提供较新的软件，隐私默认设置也合理。它是通用桌面系统，不是加固过的匿名系统，所以它抬高的是你的基线，而不是替你挡住一个认真的对手。把它当作日常主力系统；真需要匿名，那是另一类工具的事。

Fedora Atomic

Fedora Atomic 桌面系列（Silverblue、Kinoite 等）是不可变版本，基础系统只读，通过 rpm-ostree 原子更新，应用以 Flatpak 运行，内置回到旧系统镜像的回滚能力。

加密 DNS8

Unbound

官网 ↗原文

自己跑一个带验证的递归解析器，是停止信任任何别人 DNS 的办法，Unbound 就是为此而生的精简、审计充分的工具，支持 DoT。代价是你成了运营者：安装、缓存行为、上游选择都归你，这超出多数人的意愿。追求真正独立的自建者和小型网络该这么做；一个信誉良好的公共解析器已经让你满意的，没必要。

dnscrypt-proxy

官网 ↗原文

加密 DNS 的爱好者之选，支持 DNSCrypt v2、DoH，以及匿名化 DNSCrypt，能把问谁和问什么分开。这份灵活也是门槛：它是配置文件驱动的工具，普通用户会觉得比在手机上拨个开关麻烦得多。想精确指定 DNS 走向和中继的人用它很好；只想默认开个加密的人，太过头了。

RethinkDNS

官网 ↗原文

一个开源安卓应用里同时有加密 DNS 和真正按应用区分的防火墙，还不需要账号，这确实少见。拦截库的深度和设备端日志，对想核查应用到底在干什么的人很有吸引力。短板是界面要花时间学，而且 DNS 与防火墙都走 VPN 通道，意味着不能同时和真正的 VPN 并用，除非绕道。愿意投入配置时间的隐私意识安卓用户，用它合适。

DNSCloak

官网 ↗原文

对 iPhone 或 iPad 来说，它通过设备端的 VPN 描述文件把 dnscrypt-proxy 的加密 DNS 带到 iOS，填上了一个真实的空缺。直白的问题是年代：几年没有更新，实际上已被放弃，而一个被放弃的网络工具跑在变化很快的平台上就是负担。改用仍在维护的 iOS 选项；这个只留着当历史背景看。

Cloudflare

官网 ↗原文

快，配置也极简单，支持 DoT 与 DoH，可用率长期很好，所以很多设备出厂就指向它。避不开的张力是集中：把全球 DNS 的一大块交给一家美国大公司，无论其政策如何，都是真实的隐私与集中化顾虑。看重速度和省事就用它；在意减少对大基础设施的依赖，就去找更小的解析器或自己搭。

Nebulo

官网 ↗原文

一个小巧、免 root 的安卓 DNS 修改器，能加 DoH 和 DoT 而不要求系统权限，正好是很多手机用户需要的定位。期望别太高：它已经很久没更新，仍活跃维护的替代品是更稳妥的推荐。确实只想要轻量免 root 方案可以知道它，但先查有没有更新的维护版本。

Control D

官网 ↗原文

Control D 的长处是灵活：可以叠加多个拦截列表、按设备设规则，还能选择把流量从出口节点绕出去，这些基础解析器都没有。免费档对广告与恶意软件拦截确实够用，且不记录日志。短板是完整功能要付费，而流量重定向意味着你要信任 Windscribe 的基础设施。已经超出普通解析器需求、又不想要整套 VPN 的人，选它。

Quad9

官网 ↗原文

瑞士的解析器，默认拦截已知恶意域名，支持 DoT、DoH、DNSCrypt，对多数人来说是隐私与安全兼顾的合理组合。任何公共解析器都有的诚实提醒是：你把信任从运营商转移到了它身上，所以效果只等于 Quad9 宣称的不记录政策。家庭用来当没负担的默认很合适；想把一切都看清并调优的高阶用户会宁愿自己跑。

DuckDuckGo

Kagi

Mojeek

官网 ↗原文

独立性就是全部：Mojeek 在英国跑自己的爬虫和索引，确实不是套了隐私外衣的谷歌或必应。这份独立也是它的局限，索引更小，深或冷门的查询比起巨头会显得单薄。支持一个真正独立的搜索生态对你重要，且难的搜索你会退回别的引擎，就选它。需要每次都有全面结果，它暂时还比不过几家大厂。

Qwant

官网 ↗原文

Qwant 是欧洲用户最容易上手的隐私搜索引擎：免费、不要账号、按管辖受 GDPR 约束，法语支持一流。部分依赖必应索引意味着查询覆盖面扎实，不过结果的调节余地不如订阅式服务。想要免费、无摩擦、托管在欧盟、也不在乎付费替代品的定制控制，Qwant 可以作为日常可靠选项。更看重结果控制、或想彻底离开微软的数据基础设施的人，应考虑别的方案。

官网 ↗原文

它的卖点是谷歌的结果而没有谷歌的追踪，如果你觉得隐私型引擎结果偏弱、又仍想摆脱画像，这确实有用。短板是它闭源，代理的正是你可能想离开的那家公司，所以隐私这层你只能信 Startpage 的说法。结果质量不可妥协、也接受一个封闭中间人，就选它。想要不碰谷歌的独立索引，看 Mojeek。

它的最大用处是充当安卓上对应苹果健康的那一环，因为安卓没有可比的、内置的医疗记录与设备数据中心。CommonHealth 把所有内容留在你的手机上，由你决定哪些服务商和应用能看到什么，对健康信息来说这才是正确的默认。诚实的局限是，它的价值完全取决于你所在地区有哪些医疗系统和服务商支持它，投入之前先查清楚。在有对接的地方，它是比把记录交给大科技健康平台更扎实的本地优先替代。
