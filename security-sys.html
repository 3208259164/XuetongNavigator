操作系统14

NixOS

官网 ↗原文

完全基于 Nix 包管理器的 Linux 发行版，整个系统（内核、软件包、服务、配置）都声明在一组文件里。升级是原子的，可完整回滚是内置能力。

secureblue

官网 ↗原文

基于 Fedora Atomic 的安全加固不可变 Linux 系统，以 OCI 可启动容器镜像分发，应用内核加固、来自 GrapheneOS 的加固内存分配器，以及名为 Trivalent 的加固 Chromium 浏览器。

Kicksecure

官网 ↗原文

基于 Debian 的安全加固发行版，开箱即用大量内核与用户空间加固设置，在不需要手动配置的情况下缩小攻击面。它同时也是 Whonix 匿名系统的底座。

Whonix

官网 ↗原文

免费开源的桌面操作系统，强制所有流量经由 Tor 传输，由两台相互隔离的虚拟机组成（网关机与工作站）。

Qubes OS

官网 ↗原文

Qubes 把靠隔离保证安全推到极致，把各项活动放在彼此隔离的虚拟机里，一台被攻破也够不到其他。这确实强，也确实苛刻：需要够好的硬件、真实的学习曲线和耐心，所以它明确是给专家用的。如果你是高风险用户、愿意投入这份功夫，少有比它更严谨的；其他所有人只会觉得阻力超过自己的威胁模型所需。

Arch Linux

官网 ↗原文

极简的滚动更新发行版，遵循自己动手的哲学：从最基础的系统开始，逐个选择组件自建，用 pacman 持续更新。

Fedora Workstation

官网 ↗原文

从 Windows 或 macOS 转过来，想要一个现代、维护良好又不用时时照看的 Linux，Fedora Workstation 是稳妥的默认选择；它提供较新的软件，隐私默认设置也合理。它是通用桌面系统，不是加固过的匿名系统，所以它抬高的是你的基线，而不是替你挡住一个认真的对手。把它当作日常主力系统；真需要匿名，那是另一类工具的事。

Fedora Atomic

官网 ↗原文

Fedora Atomic 桌面系列（Silverblue、Kinoite 等）是不可变版本，基础系统只读，通过 rpm-ostree 原子更新，应用以 Flatpak 运行，内置回到旧系统镜像的回滚能力。

macOS

官网 ↗原文

与 Windows 11 相比，macOS 是更安静的选择：桌面里没有广告，也没有 Recall 那种屏幕记录，更多处理留在本机。它仍然闭源，某些检查会回连苹果，所以你是把微软的遥测换成苹果的遥测，默认更好，但同样要信厂商的说法。想要打磨好的桌面又不想听 Windows 的噪音，它合适。想要能完全审计和掌控的系统，下一步是 Linux 发行版。

openSUSE Tumbleweed

官网 ↗原文

Tumbleweed 站在多数发行版错过的一个甜点上：真正新鲜的软件包，加上经 Snapper 实现的真实回滚安全网，内核更新搞砸了，重启一下就能撤销，而不是进恢复模式冒险。安装器比 Arch 友好，硬件兼容性因社区维护的仓库而优秀。诚实的短板是滚动发布需要照看：更新不断到来，偶尔升级前要人工干预。想要前沿软件又不愿把系统交给混乱，它是个好选择；想要设好就不管的机器，则不太理想。

Tails

官网 ↗原文

需要在你使用的机器上不留痕迹时，Tails 就是那个工具：从 U 盘启动，所有流量走 Tor，关机后会话消失。失忆是全部要点也是短板，除非你刻意设置加密存储，否则什么都不留存，而且和所有 Tor 一样慢。在不是自己的硬件上开一个干净、用完即弃的匿名会话，用它；别指望它当日常系统。

Ubuntu

官网 ↗原文

Ubuntu 是进入 Linux 的友好入口，出问题时教程、驱动支持和论坛回答最多，对第一次切换来说这比理念更重要。要知道 Canonical 过去在隐私上出过错，也强推一些用户不喜欢的 Snap 包，所以它比 Windows 进一步，但不是隐私最大化的选择。想轻松在 Linux 上熟悉起来，选它；摸熟之后，再调默认值或换更严格的。

Parrot

官网 ↗原文

Parrot Linux 是基于 Debian 的完整操作系统，面向安全、隐私与开发。功能全但轻量，非常开放。有三个版本：通用、安全与取证。安全版用自己的沙箱体系，由 Firejail 与 AppArmor 加定制安全策略组成；取证版打包了一整套安全与渗透测试工具，类似 Kali 和 Black Arch。

Alpine Linux

官网 ↗原文

Alpine 是面向安全的轻量发行版，基于 musl libc 与 busybox。所有用户空间程序都编译为位置无关可执行文件并带栈溢出保护。对部分新用户来说，安装和配置可能相当复杂。

手机系统6

LineageOS

官网 ↗原文

任何第三方 ROM 里最广的设备支持，也是它诚实的卖点：手机太旧或太冷门、GrapheneOS 不支持，往往只有这条路能让它继续打补丁、去谷歌化。但要看清广度换来的是深度不足。加固程度因维护者而异，验证启动在少数设备之外很不稳定，所以它更适合理解为延长寿命和去臃肿，而不是最高安全。让老手机复活很好，威胁模型严肃时就是错的选择。

GrapheneOS

官网 ↗原文

只支持 Pixel，而且毫不掩饰，因为把自己绑在带验证启动的硬件上，正是它能给出比追求设备广度的对手更强保证的方式。这就是交易：买谷歌的手机硬件，来逃离谷歌的软件，沙箱化的 Play 层让真实应用仍能运行。威胁模型高但务实，它是当下最可信的手机系统。只有你拒绝拥有 Pixel 时才该跳过。

/e/OS

官网 ↗原文

想要日常主力机的安卓体验、又不把数据交给谷歌，/e/OS 开箱就比多数替代品做得多：追踪器评分、microG 兼容层、简单安装器，相比手动折腾 LineageOS 门槛低了很多。取舍是 microG 不是谷歌服务的完美替代，少数需要证明或专有 API 的应用无法正常工作。能容忍偶尔的应用摩擦、想要一个法国基金会支持、社区可审计的系统而不是自己从零搭，它最合适。

iOS

官网 ↗原文

开箱状态下 iOS 泄漏比原生谷歌安卓手机少，因为追踪要用户主动同意，苹果也不跑谷歌那套建立在你的数据上的广告机器。短板是它完全闭源，隐私依赖苹果的承诺而不是你能查验的东西，而且它仍是受法律要求约束的美国公司。对多数人来说是务实的稳妥选择。最大化的做法是 GrapheneOS 这类去谷歌化的安卓，用可验证的代码换掉苹果的口头保证。

CalyxOS

官网 ↗原文

它位于 LineageOS 与 GrapheneOS 之间：开箱的隐私工具和 microG 比前者多，设备容忍度和便利性比后者的纯粹立场多。代价是把 microG 塞进来让依赖谷歌的应用可用，确实是攻击面和信任上的妥协，GrapheneOS 刻意拒绝这么做。想要一台能用、不必每天和应用打架的去谷歌化 Pixel，选它。想要最硬的基线，GrapheneOS 更严格。

Ubuntu Touch

官网 ↗原文

真正既非安卓也非 iOS 的手机系统很稀少，这份理想主义就是它的全部吸引力。短板是主力机的现实：应用生态单薄，硬件支持窄，你会不断绕开缺口。运行一台真正的 Linux 手机本身就是目标、也把这台设备当项目来做，就选它。需要手机拿来就能用的人，另找别处。

应用商店5

Obtainium

官网 ↗原文

它的吸引力在来源：你装的就是开发者亲自发布的那份，不是被重新打包或延迟的副本。这让 Obtainium 成为 F-Droid 的有力补充，适用于自己发布签名 APK、但还没进 F-Droid 的应用。诚实的短板是配置摩擦：每个应用都要手动配，有些来源靠网页抓取，上游页面一变就断。愿意自己维护应用清单，Obtainium 给你比任何传统商店更细的更新链控制；想要一键目录式体验，它就不合适。

Accrescent

官网 ↗原文

Accrescent 的技术设计确实用心：签名密钥固定消除了其他商店留下的一整类供应链攻击，签名的元数据意味着被攻破的镜像无法悄悄换包。项目与加固安卓社区关系紧密，GrapheneOS 就在自己的应用商店里提供它。诚实的短板是 alpha 状态意味着真有粗糙之处，目录也仍然单薄：主流应用基本缺席。GrapheneOS 或 CalyxOS 上注重安全、想要当下最强的安装时完整性保证，Accrescent 值得密切关注；今天的日常应用需求，就与 F-Droid 或 Aurora Store 搭配使用。

Zapstore

官网 ↗原文

Zapstore 最好的想法是信任跟随人而不是守门人：没有中心审核队列决定谁能上架，每个发布都带可追溯到作者的签名。这适合自己出构建包、却始终没进 F-Droid 的应用。诚实的短板是无需许可的商店把更多判断交给你，因为谁都能发布，目录也比 F-Droid 或 Aurora Store 小。已经在用 Nostr、或想直接跟随特定开发者，就选它；想要一套审核政策下的精选目录，从 F-Droid 或 Accrescent 起步。

Aurora Store

官网 ↗原文

Aurora Store 巧妙地解决了一个矛盾：你拿到完整的 Google Play 目录，身份却不进谷歌的视野。相比原生 Play 商店这是真实的隐私收益。短板是结构性的：匿名会话是共用的，偶尔会被谷歌封禁或限流，下载随之中断直到会话轮换。你也在信任 AuroraOSS 对 Play API 客户端的构建，而不是谷歌控制的供应链。需要主流应用又想尽量少被追踪，Aurora Store 是实用之选；只要自由软件的纯粹派该用 F-Droid。

F-Droid

官网 ↗原文

对只装自由软件的安卓用户，F-Droid 是有原则的选择：从源码构建的流程与可复现构建，提供了 Google Play 比不了的供应链透明度。诚实的短板是选择面与时效：审核队列意味着新版本常比开发者自己的发布晚几天到几周，很多流行应用根本不在这里。给设备去谷歌化、想要可审计的软件，F-Droid 该在工具箱里；需要广泛目录和当天更新，就与 Obtainium 搭配，或保留第二个来源。

输入法5

FlorisBoard

官网 ↗原文

它仍标着早期测试，这份诚实很要紧，因为指望它是个成品会让你受挫。你拿到的是一款从零写起、尊重隐私、与谷歌无关且代码活跃的键盘，确实有前途。把它当成你选择去支持、也容忍粗糙的项目，而不是可以立刻替掉 Gboard 的东西。今天就需要可靠的自动纠错和滑行输入，就先等等或选更成熟的。

Simple Keyboard

官网 ↗原文

极简是全部卖点，而且贯彻到底：没有表情、没有滑行输入、没有拼写检查、没有网络。唯一要求就是打字、什么都不回连的人，它是最干净的选择。另一面也明显：依赖手势输入或预测的人会觉得它空到烦。就因为它做得少才选它。

AnySoftKeyboard

官网 ↗原文

长期存在、Apache 许可、在 F-Droid 上且不含谷歌二进制，这正是你对隐私键盘想要的：没有遥测、没有云、没有需要联网的理由。语言支持靠单独的附加包而不是内置，所以配置比主流键盘麻烦。预测和手势的打磨也明显落后 Gboard。正在去谷歌化、也能接受打字体验不那么顺的人，它是个扎实默认。

Indic Keyboard

官网 ↗原文

定位小众，也因此真有用：23 种语言、54 种布局，面向主流隐私键盘处理得差或干脆不管的印度系文字。用这些语言打字、又想远离云键盘，它填的是别处补不好的真实空缺。不在它目标文字范围内的所有人，没什么理由选它而不选更通用的开源键盘。特定任务的对的工具。

Transcribro

官网 ↗原文

语音输入是手机上比较安静的隐私漏洞之一，原生版本会把你的音频送去谷歌或三星转写。Transcribro 把它彻底关掉：音频从不离开设备，Whisper 的准确度足以日常依赖。短板是真的：目前只处理英语，而且是年轻的单人项目，要从 Accrescent 而不再是 Play 商店安装。经常口述、又想要私密，没有别的能接近。

第三方前端11

NewPipe

官网 ↗原文

自由的安卓应用，可播放 YouTube、SoundCloud、PeerTube、Bandcamp 等平台的内容，无需谷歌服务、账号或广告。订阅与播放列表保存在本地，可在 F-Droid 获取。

FreeTube

官网 ↗原文

开源的桌面 YouTube 客户端，支持 Windows、macOS、Linux。通过内置的本地解析器或 Invidious API 获取内容，默认拦截广告，订阅、历史与播放列表全部存在本机。

Invidious

官网 ↗原文

如果你看 YouTube 又不想被 Google 反看，这是这一类里成熟度领先很多的选择，桌面和移动端都有应用建立在它之上。真正的麻烦是 Google 不断弄坏公共实例，你今天收藏的那个下个月可能就被限流或者打不开。想要稳定就自建；否则就接受要不断换实例，手边多留一两个备用。

LibreTube

官网 ↗原文

开源的安卓 YouTube 客户端，请求经由 Piped API 转发而不直连谷歌。支持 SponsorBlock、ReturnYouTubeDislike、DeArrow、订阅、播放列表和后台播放，Material 3 界面。

Nitter

官网 ↗原文

Twitter 的开源替代前端，无需账号即可浏览。安卓端也可选用 Fritter，一个注重隐私的 Twitter 前端。

Piped

官网 ↗原文

开源的 YouTube 网页前端，可自托管，播放过程中不连接谷歌服务器。支持 SponsorBlock、播放列表、订阅和公开的 JSON API，以多实例联邦网络运行。

Redlib

官网 ↗原文

用 Rust 编写的开源 Reddit 网页前端，可自托管。所有内容（包括媒体）都经服务器代理，Reddit 看不到你的 IP，也无法用 Cookie 或 JavaScript 追踪你。

LibRedirect

官网 ↗原文

问题不在思路上，而在可靠性：只有当它指向的公共前端实例真的在线时才有用，而这些实例总是时有时无。把它当成一层便利：能改道就悄悄把你从大平台引开，别当成保证。已经自建实例、或不介意偶尔跳到死链的人会喜欢它；想设好就不用管的人会被它烦到。

Quetre

官网 ↗原文

Quora 是设墙和追踪比较凶的站点之一，一个代理所有请求、只把答案摆给你的前端就真有价值。项目偏小，和这一类其他前端一样对实例脆弱，近期活跃度也低。Quora 的答案常出现在你的搜索结果里，就装上它；它解决的是真实的烦人之处，还不用你登录。

libremdb

官网 ↗原文

一个窄工具只做一件事：把 IMDb 挡在你和它热衷的追踪之间，客户端从不直接碰 IMDb。诚实的局限和这里每个前端一样：你信任所选的公共实例，项目小意味着实例少，还可能消失。经常查影视资料到在意的程度，它值得；一年看两次 IMDb，就过头了。

rimgo

官网 ↗原文

专治一个具体的烦人之处：打开 Imgur 链接时不再遇到注册提示、应用推销和真正的站点带来的追踪。它是薄前端，命运取决于公共实例是否在线，以及 Imgur 不在底下改东西。偶尔遇到图片链接时当个快捷代理就行；谁也不必为它多想。

浏览器与扩展31

Helium

官网 ↗原文

隐私优先的 Chromium 浏览器，默认启用 uBlock Origin 与追踪拦截，基于 ungoogled-chromium，支持 Windows、macOS、Linux。

uBlock Origin

官网 ↗原文

如果只装一个隐私扩展，就装它。uBlock Origin 轻量、免费、开源，能力远超那些顺手卖你数据的广告拦截器，进阶模式还能把第三方请求管得远超广告范围。唯一实在的提醒是 Chrome 转向 Manifest V3 削弱了拦截器，所以它在 Firefox 上满血，在 Chrome 上是能力缩水的 Lite 版。在 Firefox 上几乎没得商量。

Firefox Focus

官网 ↗原文

专注隐私的移动浏览器，自动拦截追踪和广告。页面加载更快，数据留给自己。

SponsorBlock

官网 ↗原文

SponsorBlock 更偏生活质量而不是隐私工具，众包赞助口播和片头的时点，让播放器自动跳过，免费开源。诚实的提醒是它依赖志愿者已经标注过某个视频，较新或冷门的片段可能没被覆盖，而且它是 YouTube 的使用便利，不是防追踪。装它是因为看得更舒服，不是因为它保护你；要保护，就配一个真正的拦截器。

Brave

官网 ↗原文

快速的跨平台 Chromium 浏览器，默认拦截广告与追踪器，开箱即用，适合新手或不想花时间配置的人。

uBlock Origin Lite

官网 ↗原文

权限模型是这里的主要故事：基础模式下它拦广告和追踪器，却不要求访问你访问的每个站点，相比经典扩展是实质的安全改进。它是 iOS 上 Safari 推荐的内容拦截器，那里没有别的强选择。诚实的短板是 MV3 对规则数量有硬限制，也封掉了动态过滤，所以达不到完整 uBlock Origin 的深度。用不了原版的 Chrome 和 Safari 用户、或想要更轻浏览器权限的人，选它合适。

Cromite

官网 ↗原文

已停止的 Bromite 的活跃后继，给安卓（现在也有桌面）一个内置广告拦截和 DoH 的 Chromium 构建。诚实的背景是它只是众多分叉之一，你要信一个更小的维护者跟得上 Chromium 持续不断的安全更新，这是真实的负担。专给安卓上加固 Chromium 的好选择；iOS 上、或你偏好 Gecko 引擎，它不适用。

Mullvad Browser

官网 ↗原文

把 Tor 项目的抗指纹措施套到正常浏览体验上，这个组合确实有吸引力。每个 Mullvad Browser 用户共用同一个指纹，这本身就是设计目标，所以即使不在 Tor 上，它对抗追踪也很稳。短板是永久的无痕模式意味着没有持久登录、没有保存的标签页，随意的用户会烦。已经跑着 VPN、想要浏览器层面抗追踪又不想转 Tor 的桌面用户，最合适。

ClearURLs

官网 ↗原文

ClearURLs 把链接里的追踪垃圾剥掉，也就是那些跟着你在站点之间跑的 utm 和点击 ID 长参数，在后台安静完成。它是小而专注的工具，单靠自己不会改变你的隐私面貌，偶尔还会把需要某个参数才能工作的链接裁过头。作为低成本的附加层，和一个真正的内容拦截器一起用；别指望它带来日常能察觉的变化。

Onion Browser

官网 ↗原文

在 iOS 上它实际上是接入 Tor 网络唯一真正可行的路径，这就够它存在了。对简介里暗示的短板要看清楚：苹果强制所有浏览器用 WebKit，所以它没法达到真正 Tor Browser 的匿名保护，某些泄漏不可避免。在 iPhone 上随手访问 onion 服务或轻度匿名，用它；威胁模型严肃，就在桌面用 Tor Browser 做那件事。

xBrowserSync

官网 ↗原文

xBrowserSync 在浏览器和设备之间同步书签与标签页，数据在客户端加密，所以你可以不用谷歌或 Mozilla 账号做同步，还保住便利。它是窄工具不是隐私套件，可用性上你信任的是社区服务器或自建的那个。想要跨浏览器同步又不愿把书签清单交给大厂、也不介意稍麻烦的配置，它值得。

Cookie AutoDelete

官网 ↗原文

Cookie AutoDelete 在你关掉标签页的瞬间清掉该站点的 cookie，正好杀掉让站点跨会话认出你的持久标识。代价是摩擦：除非你仔细把信任的站点加白名单，否则会不断被登出，很多人最后放弃、白名单加得过宽。它奖励有纪律的人，烦到其他所有人；容器标签页已经覆盖了你的话，可能根本不需要它。

Firefox

官网 ↗原文

可靠、快速且注重隐私的浏览器。可以配合扩展加固，开启 DNS over HTTPS，并在各设备间同步。

AdGuard

官网 ↗原文

Safari 内容拦截器里能力少见地强，远不止隐藏广告，还做广泛的追踪与外观过滤，而且开源。要知道 Safari 在这里怎么运作：苹果的内容拦截模型限制了任何扩展能深到哪，所以即使这么强的拦截器也做不到系统级工具的全部。Mac 和 iOS 上想在浏览器内强力拦截的 Safari 用户，它是个扎实选择；要覆盖每一个应用，就再配网络层过滤。

Decentraleyes

官网 ↗原文

Decentraleyes 在本机提供常用代码库，让你的浏览器不再每个页面都去敲谷歌等公司的 CDN，切掉一条安静的追踪通道。诚实的局限是内置的库会陈旧，现代站点越来越多用它不覆盖的库，这些年保护面已经收窄。和 uBlock Origin 搭配无害，但单靠自己现在只是小补充，而不是能实质改变暴露面的工具。

IronFox

官网 ↗原文

用过 Mull、想继续留在加固的安卓 Firefox 上，IronFox 是自然的延续。加固补丁和隐私向的默认设置，让它在普通安卓 Firefox 面前有真实优势，开放许可意味着社区可以独立审计和维护。主要短板是开发者基数小：这种规模的项目靠持续的志愿投入，完全托付之前先看发布节奏。高阶用户和 GrapheneOS、CalyxOS 的使用者是显而易见的受众；随意的用户可能觉得配置面超出所需。

LibreWolf

官网 ↗原文

隐私和抗指纹的活已经替你做好的 Firefox，省掉那张手动加固清单。取舍在便利这边：它去掉遥测和 Pocket 类附加功能，会弄坏一些依赖 Firefox 默认行为的站点，更新也比上游稍慢。想要加固过的 Firefox 又不想折腾，它很理想；需要一切都顺畅能用，普通 Firefox 加几个扩展更温和。

Orion

官网 ↗原文

扩展兼容这块确实少见：在 WebKit 外壳里同时跑 uBlock Origin 和 Safari 扩展，别的浏览器给不了。隐私默认很强，零遥测的说法与商业模式相符，靠用户资助、没有广告交易。诚实的短板是 Orion 闭源，所以零遥测的断言无法在代码层面独立验证。想要 Chromium 之外的扩展触达、也愿意信任一家小商业公司的 macOS 与 iOS 用户，它合适。

Privacy Badger

官网 ↗原文

拦截隐形追踪器，阻止广告商和其他第三方偷偷记录你去过哪里、看了什么页面。比 uBlock 更简单、可配置项更少，只针对追踪器，不拦广告。

Firefox Multi-Account Containers

官网 ↗原文

把在线生活的不同部分分进按颜色区分的标签页，从而保护隐私。cookie 按容器隔离，可以同时用多个身份或账号上网。

WebRTC-Leak-Prevent

官网 ↗原文

让 Chromium 用户能自己控制 WebRTC 隐私设置，防止 WebRTC 泄漏。Firefox 用户可直接在浏览器设置里关掉。可以用 browserleaks 的 WebRTC 页面自测是否泄漏。

Canvas Fingerprint Blocker

官网 ↗原文

在不剥夺网页使用 HTML5 Canvas 的前提下阻断指纹。Canvas 指纹常被用来追踪，这个扩展通过不让浏览器生成真正唯一的键来减轻这种追踪。

Privacy-Oriented Origin Policy

官网 ↗原文

在 Origin 头最不必要的时候阻止 Firefox 发送它，以保护隐私。

LocalCDN

官网 ↗原文

模拟远程框架（如 jQuery、Bootstrap、Angular），改由本地资源提供，避免向追踪型 CDN 发出不必要的第三方请求。

PrivacySpy

官网 ↗原文

PrivacySpy.org 的配套扩展。那个开放项目给隐私政策打分、加注并归档，扩展会显示当前网站隐私政策的分数。

Flagfox

官网 ↗原文

显示一面国旗，标出当前网站服务器的所在国家，一眼就能看到。点图标还有更多工具：站点安全检查、whois、校验等。

AmIUnique Timeline

官网 ↗原文

帮你更好地理解浏览器指纹的演变，也就是网站用来唯一识别和追踪你的那套东西。

Netcraft Extension

官网 ↗原文

访问已知或可疑的钓鱼网站时提醒你，并检测可疑的 JavaScript，包括盗刷脚本和挖矿脚本。还会给站点的正当性与安全性一个简明评分，对不太懂技术的人很友好。Netcraft 另有在线工具 Site Report，可以查任意网站跑的是什么。

DeArrow

官网 ↗原文

众包的浏览器扩展，用社区提交的版本替换 YouTube 视频标题和缩略图，压掉标题党。

Floccus

官网 ↗原文

简单高效的书签同步，可以用 Nextcloud 书签、WebDAV 服务器（本地或远程），或者仅通过 LoFloccus 用本地文件夹。扩展支持 Chrome、Firefox 和 Edge。

Unmark

官网 ↗原文

一个网页应用，把书签当待办来管。可以自建，也可以用它的托管服务，有免费和付费档。

搜索引擎9

SearXNG

官网 ↗原文

SearXNG 真正划算的地方是自建，因为这样就没有第三方，哪怕是友善的实例运营者，也看不到你的查询；它在你自己屋檐下汇总多家引擎的结果。短板也在这里：跑起来要功夫，而公共实例虽然方便，却意味着信任运营者，还可能被上游引擎限流或封禁。技术上够格自建、想要没有中间人的元搜索，就选它。其余人把公共实例当成不错但不理想的捷径。

Brave Search

官网 ↗原文

建立在 Brave 自有的独立索引上，而不是转售谷歌或必应，这是有意义的差别，也越来越少见。它闭源、在美国，结果虽在改进，遇到冷门或极本地的查询仍可能落后谷歌。想真正打破谷歌与微软的双头垄断、而不是悄悄替它们转售，也能容忍偶尔单薄的结果页，就选 Brave Search。只在意结果与谷歌持平的人，用 Startpage 这类代理可能更少挫折。

DuckDuckGo

官网 ↗原文

对多数离开谷歌的人来说，DuckDuckGo 是现实的入门：开箱可用，不用注册账号，应用还会替你挡追踪器。在安全这件事上它是可靠的默认：不给你建档，也不卖，搜索走加密连接。诚实的短板值得知道：结果高度依赖必应，公司在美国，只有部分代码开放可查。这些都不否定它作为隐私默认的资格。推荐给想要真正隐私升级又不想学的朋友；当必应来源的结果不够时，把纯粹派指向独立索引。

Kagi

官网 ↗原文

用户付费的模式让 Kagi 的隐私承诺可信：没有广告主要服务，就没有财务理由去追踪点击。结果质量见仁见智，但能把劣质内容农场从结果里永久下压，是实打实的差异点。明显的短板是价格：它是这个目录里唯一需要为日常使用付费的搜索引擎，这个价位会把很多用户挡在外面。已经在为整套隐私工具付钱、希望搜索也跟上的人，选它。

Mojeek

官网 ↗原文

独立性就是全部：Mojeek 在英国跑自己的爬虫和索引，确实不是套了隐私外衣的谷歌或必应。这份独立也是它的局限，索引更小，深或冷门的查询比起巨头会显得单薄。支持一个真正独立的搜索生态对你重要，且难的搜索你会退回别的引擎，就选它。需要每次都有全面结果，它暂时还比不过几家大厂。

Qwant

官网 ↗原文

Qwant 是欧洲用户最容易上手的隐私搜索引擎：免费、不要账号、按管辖受 GDPR 约束，法语支持一流。部分依赖必应索引意味着查询覆盖面扎实，不过结果的调节余地不如订阅式服务。想要免费、无摩擦、托管在欧盟、也不在乎付费替代品的定制控制，Qwant 可以作为日常可靠选项。更看重结果控制、或想彻底离开微软的数据基础设施的人，应考虑别的方案。

Startpage

官网 ↗原文

它的卖点是谷歌的结果而没有谷歌的追踪，如果你觉得隐私型引擎结果偏弱、又仍想摆脱画像，这确实有用。短板是它闭源，代理的正是你可能想离开的那家公司，所以隐私这层你只能信 Startpage 的说法。结果质量不可妥协、也接受一个封闭中间人，就选它。想要不碰谷歌的独立索引，看 Mojeek。

Uruky

官网 ↗原文

无广告的私密搜索引擎，主打个性化。除自有数据外，也使用 Mojeek、Marginalia 等提供方。总部在欧盟，不保存也不追踪任何个人数据。它不是完全开源，但付费客户满 12 个月后可获得一份源码。

PriEco

官网 ↗原文

独立的网页搜索引擎，索引在成长中。位于欧盟，完全开源，可通过 Goggles 自定义。
