效率工具12

LibreOffice

官网 ↗原文

桌面办公套件的默认选择，适合想让文档始终留在自己磁盘上、不上云、不要账号、不发遥测的人。诚实的取舍是界面在商业套件旁边显得旧，云端协作偏弱，实时共同编辑不是它的强项。离线、私密、功能齐全的文档处理选它；实时协作才是重点，另找别家。

Etherpad

官网 ↗原文

长期运行、部署广泛的协作编辑器，快速开一个共享文档很好用，背后有庞大的插件生态。标签上写得很直白：文档不加密，所以谁运营服务器谁就能读到全部内容，信任完全取决于托管方。临时团队笔记和头脑风暴可以自建实例；别把敏感内容放进公共实例。

ONLYOFFICE

官网 ↗原文

如果你真正的问题是兼容微软 Office 又不想把文件交给微软，它处理 .docx 和 .xlsx 比多数开放替代品更忠实。注意它对加密的定位：保护传输中的数据，以及你自己服务器上的存储，不是 CryptPad 那种浏览器端零知识模型。整天泡在 Office 格式里的团队可以自建；主要想要客户端加密的，这不是那个工具。

Vikunja

官网 ↗原文

可自建的待办与项目应用，真能导入 Todoist、Trello 和 Microsoft To-Do，离开这些服务就没那么痛。两个诚实提醒：它不加密，隐私来自你拥有服务器；原生应用还粗糙，主要靠网页版撑着。会自建、想把任务数据从大厂挪走的人，它是强选；今天就需要打磨好的手机应用，则不太合适。

Collabora Online

官网 ↗原文

已经在跑 Nextcloud 或类似自建云，Collabora Online 是能给它配上的最完整办公编辑层，LibreOffice 格式兼容性强，又不把文档发给第三方服务。免费的社区版很适合小团队和个人自建者。实际的限制是部署要熟悉容器和服务器管理，这不是消费级产品。已经决定自建的组织，用这个代价换办公编辑的完整数据主权，可以接受。

CryptPad

官网 ↗原文

突出之处是加密在你的浏览器里完成，数据到达服务器之前就已经是密文，所以连托管方都读不到你的文档，同时还有一整套编辑器和 CryptDrive。代价是性能与打磨：比 Google Docs 更重更粗，大而复杂的文档会暴露这点。文档的保密性比顺滑更重要时选它；随意的协作，这份摩擦可能不值。

EtherCalc

官网 ↗原文

Etherpad 的表格版，想实时共享表格又不想被谷歌账号挡在门外时很好用。同样直白的提醒在这里更要紧，因为涉及数字：它不加密，托管方看得到你的数据，而且这里的许可信息不明确。在你控制的实例上做非敏感的协作计算没问题；数字一旦私密，就该换加密工具。

PrivMX

官网 ↗原文

波兰出的一款一体化加密团队协作套件，涵盖聊天、通话、文件、任务和看板，对隐私优先的工具来说野心不小。开发闭源、没有公开仓库，意味着你对加密的信任比对开源项目要更多落在厂商口头上，把整个团队的工作搬进去之前先考察清楚。适合想要一个可自建加密枢纽、也愿意做这份考察的组织；个人用单一用途的工具更好。

Super Productivity

官网 ↗原文

尊重隐私的开源任务管理器与时间追踪工具。数据全部存在本地，不要账号、不依赖云、零遥测。支持 Jira、GitLab、GitHub、Gitea、OpenProject 和 CalDAV 集成，带时间记录、番茄钟、休息提醒和空闲检测。

Mindwtr

官网 ↗原文

把 GTD 与番茄钟合在一起的生产力系统，有桌面和手机端。本地优先，不要账号，可通过 WebDAV、Dropbox、本地文件或自建部署同步。提供命令行、REST API 和 MCP 以便脚本化，AI 可选且自带密钥。

Sandstorm

官网 ↗原文

用来自建网页应用的开源平台。装好之后，可以从 Sandstorm 应用市场一键装东西，灵活度大致和 NextCloud 相当。

BentoPDF

官网 ↗原文

可自建的 PDF 工具集，在浏览器里完成简单和进阶的编辑、签名与整理。所有处理都在你的设备本地完成。

日历11

Proton Calendar

官网 ↗原文

端到端加密的日历，连事件详情和标题都对服务商隐藏，这很少见也真有价值，尤其你已经在 Proton 生态里。诚实的局限很实际：最好的功能在付费方案后面，全加密日历也牺牲了谷歌那种顺滑的分享与集成。把你的日程当作敏感数据，选它。习惯主流便利的人会觉得它比预想的更封闭。

Radicale

官网 ↗原文

想把日历和联系人从谷歌、苹果的服务器上拿开，又要尽量少的复杂度，Radicale 是最直接的路径。配置极简，文件格式可迁移，GPLv3 代码库从 2008 年维护到现在。短板是自建 CalDAV 服务器有运维开销：服务器、TLS，最好还有备份，才够可靠到替代托管服务。自建带来的隐私是真实且有意义的，但它不是端到端加密。安卓配 DAVx5、桌面配一个 CalDAV 客户端，就能替代 Google 日历，而不在任何第三方服务器上留下你的日程副本。

Tuta

官网 ↗原文

零知识、跨平台的日历，有真正可用的免费档，与它的加密邮件绑得很紧，这既是吸引力也是约束。加密意味着它不说标准 CalDAV，与外部应用同步受限，想用好就得投入 Tuta 的应用。这份锁定是隐私的代价。已经在其邮箱里、或正打算迁过去，它是强选；想要能接入一切其他应用的日历，就别扭。Tuta 会删掉六个月未登录的免费账号，之后也不回收那个地址：失效的名字会被禁止重新注册，要找回得订阅付费方案并用原账号的凭据登录。偶尔登录一次没问题，注册个免费地址然后忘掉，就是真陷阱。

Peergos

官网 ↗原文

Cure53 的审计是实打实的信誉标记，整体愿景也有野心：一个加密、自持的存储与应用平台，日历只是其中一块。这份广度也是要留意的地方，项目更年轻、更小众，日历不像专门工具那样打磨成独立成品。它的去中心化存储哲学合你胃口，可以一看。今天只想要一个可靠的加密日历，更专注的选项更稳。

EteSync

官网 ↗原文

自建这条逃生通道才是真正的吸引点：自己跑服务器就完全跳过订阅，同时保留端到端加密、对标准友好的日历与联系人同步。另一面是开发已经安静下来，把数据押上去之前先权衡。适合想要自己拥有服务器、看重 CalDAV 式兼容的技术用户。想要有人替你托管、且项目活跃，就不太理想。

SilentSuite

官网 ↗原文

桥接才是它值得一看的原因。多数加密同步要求你搬进它自己的应用，SilentSuite 把加密留在你的设备上，同时给普通的桌面日历一个明文的 CalDAV 端点去对接，这正是试一试的工具和长期用下去的工具之间的差别。短板是覆盖面：没有原生 iOS 同步，配置里有 iPhone 就只能在浏览器里开网页版，内置日历和通讯录什么也收不到。项目年轻，付费档养着托管那一侧。想要 EteSync 式还在被开发的加密同步，自建或付费托管，选它；苹果设备是核心，就先跳过。

Nextcloud Calendar

官网 ↗原文

自建 Nextcloud 平台的日历应用，用 CalDAV 在设备间同步，不支持端到端加密。

Fossify Calendar

官网 ↗原文

出自 SimpleMobileTools 停更后分叉出来的 FOSS 应用家族，简单、可定制，带小部件。要注意目前对 CalDAV 的支持有限。

KashCal

官网 ↗原文

离线优先的安卓日历，可与 iCloud、CalDAV 和本机日历同步。不要账号，没有遥测，凭据存在安卓密钥库中。事件本身不是端到端加密，同步安全取决于你的服务商。

Tymeslot

官网 ↗原文

开源（AGPL-3.0）、可自建的日程与日历平台。访客不用注册就能预约；主理人得到一个完整日历，可与谷歌、Outlook、iCloud 双向同步。也提供托管云方案。

Rallly

官网 ↗原文

开源、可自建的排期工具，帮你找出大家最合适的碰头时间。定几个选项建个投票，把链接发出去让大家勾选可用时间，省掉来回发邮件。

Loop Habit Tracker

官网 ↗原文

无广告、开源、数据只在本机，背后有一大批长期用户，对一个这么简单的应用来说是很高的信任。另一面是它只做一件事：习惯打卡的连续天数和图表，不去当计划表或日记本，目标定得很重的人迟早会觉得不够用。这份专注正是它的吸引力：想在安卓上清爽地记习惯、不要账号、不被推销，选它；需要把提醒挂在一整套任务系统上的，另找别家。

Stretchly

Workrave

Euki

官网 ↗原文

在开源项目里算很小的，但这样评价低估了它：Euki 与其说是业余项目，不如说是为性与生殖健康专门做的工具，数据存在本机，确实保护了用户。你输入的东西一点都不会上云，它甚至准备了诱饵 PIN，应付有人强行打开应用的场合。你在意的威胁是别人亲手翻你手机、而不是服务器被攻破时，就选它。只是要知道，这里内容库的质量和隐私同样重要。

Apple 健康

官网 ↗原文

把一款预装的闭源苹果应用收进隐私目录，是务实的选择，不是纯粹主义的选择。它真正站得住脚的地方是，健康数据默认加密并留在本机，而不是喂给某家第三方健身公司，苹果也不出售这些数据。你仍然是在相信苹果的说法，而不是可审计的代码，这就是交换。有 iPhone、想要一个私密的健康记录归集处，内置的这个胜过再装一个追踪应用；开源的信徒不会满意。

AutoSleep

官网 ↗原文

通过 Apple Watch 自动追踪睡眠，数据处理完全在本地，注重隐私。

Apple 健身记录

官网 ↗原文

苹果内置的活动与健身记录应用，配合 iPhone 与 Apple Watch 使用，健康数据在设备端处理，通过端到端加密同步到 iCloud，苹果无法读取。

drip

官网 ↗原文

月经数据正是你不希望躺在别人服务器上的那种东西，drip 的答案是全部留在设备上，根本不要账号。代价是没有云备份，手机丢了或被清空，历史就没了，与打磨精致的商业经期追踪应用相比它也刻意朴素。追踪生殖健康、把那类数据当敏感信息的人，纯本地模型就是全部要点，缺掉的便利值得。

Gadgetbridge

官网 ↗原文

真正的吸引点是把你的手环或手表从厂商应用里解放出来，不用账号、不用把数据上传给厂商也能用硬件。短板是兼容性：Gadgetbridge 支持特定清单里的设备，你手上那只可能完全支持、部分支持、或者完全不支持。买之前或决定之前先查清单。被逼着装闭源配套应用才能看自己步数的人，这是开源的逃生口，带着一贯的粗糙。

HeartWatch

官网 ↗原文

闭源、只做 iOS，所以无追踪、无第三方代码、不上传这些说法靠的是开发者的信誉而不是可查验的代码。在这些限制之内，它是个专注的方式，把你 Apple Watch 采集的一切读出来，而不必有个分析 SDK 在旁边盯着。想要比 Apple 健康更丰富的心率和健身洞察，也宁可信一个小额付费应用而不是免费带广告的，它值得。可验证的隐私是你的门槛，闭源应用过不了。

CommonHealth

官网 ↗原文

它的最大用处是充当安卓上对应苹果健康的那一环，因为安卓没有可比的、内置的医疗记录与设备数据中心。CommonHealth 把所有内容留在你的手机上，由你决定哪些服务商和应用能看到什么，对健康信息来说这才是正确的默认。诚实的局限是，它的价值完全取决于你所在地区有哪些医疗系统和服务商支持它，投入之前先查清楚。在有对接的地方，它是比把记录交给大科技健康平台更扎实的本地优先替代。

OpenHabitTracker

官网 ↗原文

免费开源的习惯追踪器，可以记笔记、规划任务、追踪习惯。数据全部本地保存，或用 Docker 自建，不要账号。

智能家居7

Home Assistant

官网 ↗原文

这一类里没有别的能比 Home Assistant 的集成广度和自动化引擎的深度。本地处理意味着厂商的云挂了你的灯照样能用，使用数据也不离开家。真正的代价是复杂度：初始搭建、进阶自动化要写 YAML 配置、还要自己管更新，这把它牢牢放在爱好者领域。从 Google Home 或 Alexa 过来的人要预期一段陡峭的学习曲线。认真对待隐私与设备寿命的人，这份投入会回本；随意的智能家居用户，开箱体验会比商业方案粗糙。

Domoticz

官网 ↗原文

Domoticz 的名声来自在低配硬件上跑得舒服：树莓派 Zero 或第一代派就能扛住一个不大的安装，这对常开的家居自动化很重要。全本地架构意味着没有厂商能关掉你的系统，硬件支持清单也确实宽。短板是界面没跟上现代交互预期，配置流程比 Home Assistant 现在的面板工具显得过时。想要在极简硬件上长期运行、也能接受实用主义界面，Domoticz 是可靠的选择；想要打磨好的搭建体验，先看 Home Assistant。

ioBroker

官网 ↗原文

ioBroker 的适配器生态是它最强的论据之一：有些平台只能靠通用 MQTT 桥接，ioBroker 往往已有原生适配器，处理某个设备家族的怪癖。JavaScript 与 Node.js 的基础也让写自定义适配器对熟悉这套栈的开发者很顺。诚实的短板是管理界面和初始搭建不如 Home Assistant 现在的体验精致，分布式适配器架构意味着更多要维护更新的部件。想用 JavaScript 写自定义逻辑、或需要覆盖 Home Assistant 处理得不好的设备协议，它是最佳选择；刚接触家居自动化的人，有更友好的起点。

openHAB

官网 ↗原文

openHAB 的厂商中立设计和深厚的 OSGi 架构，让它适合需要把传统工业协议（KNX、Modbus）与现代物联网设备一起桥接的集成者，这是 Home Assistant 只能靠插件补上的能力。一切跑在你自己的硬件上，完全本地控制。诚实的短板是 Java 与 OSGi 技术栈以及规则 DSL 的学习曲线比多数对手陡，界面工具也落后于 Home Assistant 现在提供的。技术用户手里既有商业设备又有自制设备、想要一个稳定、有基金会支持的平台，openHAB 是认真的选择；新手，上手过程要难得多。

HomeKit

官网 ↗原文

作为主流智能家居平台，它的隐私姿态很强：家庭数据端到端加密，摄像头分析在你家的中枢上完成而不是公司云端，苹果也没有广告理由去开采它。局限是苹果惯有的那些：封闭生态，指望你买带对应标志的苹果硬件和配件，也没法自建。iPhone 家庭想要比 Alexa 更好的隐私、又不想跑服务器，这是省心的选择。要完全控制和任意厂商支持，Home Assistant 是那扇逃生门。

Gladys Assistant

官网 ↗原文

开源、尊重隐私的家庭自动化，兼容树莓派、台式机、NAS 等大量设备。开发活跃，法语社区不错，集成也多（Zigbee、飞利浦、摄像头、涂鸦、MQTT、Telegram 等）。

Secluso

官网 ↗原文

开源、端到端加密的家用安防摄像头方案，基于 Pi Zero 2W。用图形化的部署工具就能轻松搭好。通过手机应用和不可信的自建中继，实现完整的端到端加密远程访问，包括实时画面与智能移动告警。

加密货币与支付17

Electrum

官网 ↗原文

老牌的轻量比特币钱包，因为不下载整条链所以快，支持硬件钱包，也有自己的去中心化服务器。这种轻量模型的另一面是默认连接公共服务器，它们看得到你查询了哪些地址，所以注重隐私的用户该把它指向自己的节点。想要成熟、不加修饰、哪都能跑的钱包、也愿意配置服务器，选 Electrum。想要有人手把手带的新手，可能更喜欢更引导式的。

Sparrow Wallet

官网 ↗原文

为认真对待比特币自持和钱包隐私的人而建，内置 CoinJoin 和强 Tor 支持，让交易历史在链上更难被关联。取舍是只做桌面端，并默认你懂币的选择和 UTXO，对只想要一个余额数字的人属于杀鸡用牛刀。自己跑节点、或想细粒度控制钱包隐私足迹，选 Sparrow。不想学 UTXO 管理的普通持有者会觉得它吓人。

Monero GUI Wallet

官网 ↗原文

官方钱包，想要最直接、维护最好的门罗持有与管理方式、且完全掌控自己的密钥，它就是稳妥默认。取舍是分量：跑好它要处理全节点或者信任远程节点，比轻量钱包麻烦。想要参考客户端、密钥在设备上由自己控制，它合适；想要更轻的，下面还有别的选项。

Cake Wallet

官网 ↗原文

自持是这里的地基：Cake Wallet 不代你持有任何东西，门罗的本地扫描做法相比把活外包给远程服务器的钱包是具体的隐私改进。代码库在 cake-tech/cake_wallet 下开源，所以非托管的说法可验证，而不只是宣称。取舍是自己管密钥就意味着丢了助记词就失去访问，没有恢复选项。把自持密钥看得比托管服务的便利更重要的人，这个取舍值得。

Feather Wallet

官网 ↗原文

更轻、更快的门罗桌面钱包，很多人日常用起来比官方客户端更顺，还额外支持 Tails，对注重隐私的配置是受欢迎的加分。作为更小的项目，它要求你对一支更精简的团队多一点信任，不过 BSD 许可和活跃开发让人安心。觉得官方钱包重、想要一个灵活但仍把密钥留在你手里的客户端，选它。

Monerujo

官网 ↗原文

在安卓手机上管理门罗的实际答案，支持多钱包、二维码扫描，还有支付比特币地址这类便利功能。诚实的提醒是所有手机钱包共有的：手机比加固过的桌面更不适合放密钥，所以余额保持适度、设备保持锁住。日常在外访问，它是个扎实选择；价值更大时，用桌面钱包。

Wasabi

官网 ↗原文

全部卖点都在钱包层的隐私：非托管，用无需信任的 CoinJoin 让你这些币的历史在链上更难追踪，默认走 Tor。短板是 CoinJoin 涉及费用和学习曲线，而且它是桌面钱包，面向真在意链上分析的用户。链上交易隐私是真实目标、也愿意花时间正确使用 CoinJoin，选 Wasabi。只想持有和发送，更简单的钱包摩擦更小。

Edge

官网 ↗原文

这里的便利选项，手机钱包，指纹解锁，支持多种资产，适合想要自持又不想搭桌面的人。相对桌面钱包的诚实取舍是，手机客户端在高级链上隐私控制上给得更少，高阶用户会想要更多。想要一个自己掌控、加密的手机钱包而不是把密钥放在交易所，选 Edge。专注深层交易隐私的，去看支持 CoinJoin 的桌面钱包。

ZCash

官网 ↗原文

用零知识证明这种隐私密码技术，让两个用户交易时不必暴露真实身份或地址。Zcash 区块链有两类地址和交易：Z 开头的私密，T 开头的像比特币一样透明。

Trezor

官网 ↗原文

开源、跨平台、离线的加密钱包，兼容 1000 多种币。私钥在设备上生成、从不离开，所有交易由 Trezor 签名，钱包被盗的风险因此降低。Windows、Linux、macOS、安卓、iOS 都有原生应用，也能与其他钱包（如 Wasabi）配合。备份可以手抄助记词，或复制到另一台设备。用起来简单直观，同时可定制性很强，进阶功能很多。

CryptoSteel

官网 ↗原文

一块钢板，字母刻上去后可以永久拧紧固定。防火、防震、防水、不生锈，是不错的加密货币备份方案。

BitBox02

官网 ↗原文

开源硬件钱包，支持安全的多签，还可以把备份加密存到 MicroSD 卡上。

Bisq

官网 ↗原文

开源的点对点应用，可以用本国货币买卖加密货币。完全去中心化，不需要注册。

RoboSats

官网 ↗原文

私下把比特币换成本国货币的简便方式。它简化了点对点交易流程，用闪电网络的 hold 发票把托管与信任要求降到最低。确定性地生成的虚拟形象，帮助用户保持好的隐私习惯。

Umbra

官网 ↗原文

EVM 上的隐身地址协议。可以把款项发到一个由收款方控制的一次性地址，无需对方交互，在遵守良好使用习惯的前提下提升不可关联性，而不必依赖混币器或资金池。

Privacy.com

官网 ↗原文

口碑不错，是美国最大的虚拟卡服务商。与其他家不同，个人使用免费（每月最多 12 张卡），没有费用，应用与支持也做得好。另有每月 10 美元的付费方案，百分之一返现，每月 36 张卡。

MySudo

官网 ↗原文

远不止虚拟卡，MySudo 是一个用来创建隔离身份的平台，每个身份有自己的虚拟卡、虚拟号码、虚拟邮箱、消息、私密浏览等等。免费方案最多 3 个身份，付费每月 0.99 美元起。

隐私服务4

PrivacyNotes: Private Notebooks in 2026 - PrivacyTools.io

官网 ↗原文

这是我们希望存在的那种私密工作区，所以自己做了出来。注册只用一个短语，没有任何邮箱或密码与你绑定：恢复短语就是密钥，自持意味着只有你拿着它。这对那些你绝不会放进 Notion 的数据最要紧，比如一次剂量调整或难熬的一周，所以情绪与用药记录和笔记享受同一层加密。客户端开源，你可以读它怎么工作。想要一个应用装下所有私人事务、并在你的设备上加密，就选它。

VERNAM: Private File Encryption in 2026 - PrivacyTools.io

官网 ↗原文

做 VERNAM 是因为锁一个文件不该意味着装软件或信任服务器。一切都在页面里完成，文件与口令从不离开设备，你可以在加密前先拔掉网络来证明这一点。整个工具开源、可免费自建，所以隐私说法由你去核实而不是靠信。口令是唯一的钥匙，因此没有账号可攻破，也没有后门可找。需要存放或交付一个只有你能打开的文件时，就用它。

Internxt

官网 ↗原文

开源、经过审计、注册不问个人数据，还有免费 10GB，对云存储来说这是少见干净的隐私姿态。诚实的定位是它更小更年轻，生态、应用成熟度和功能深度都落后于大型加密存储品牌。偶尔的终身方案对想避开循环付费的人是真吸引。可验证的隐私优先供应商比样样精致的功能够重要，就选它。

Incogni

官网 ↗原文

一个真有用的服务，替你把向数据经纪商发删除请求这件枯燥活自动化，而几乎没人会手工大规模去做。不过预期要摆正：它只能向覆盖到的经纪商请求删除，是持续订阅，而且它是减少而不是抹掉你的暴露。想让经纪商记录被持续削掉又不愿填表的人，它值得。愿意手工提交退出请求的人，大部分能免费复现。
