查看任意安卓应用里有多少、分别是哪些追踪器，在安装某个安装包之前先了解数据会被怎样采集，同时显示应用申请的权限。

Panopticlick

官网 ↗原文

检查你的浏览器是否经得住追踪。分析浏览器与扩展对抗在线追踪技术的能力，以及你的系统配置是否独一无二、因此可被识别。

Phish.ly

官网 ↗原文

分析邮件，检查其中的网址，并对附件计算 SHA256 与 MD5 哈希，附上 VirusTotal 链接。用法是把可疑邮件转发到 scan@phish.ly，自动回复会带结果。他们声称分析后所有邮件数据都会清除，但仍建议不要放敏感信息，并用一个转发地址。

Browser Leak Test

官网 ↗原文

显示你的浏览器泄漏了哪些个人身份数据，便于更好地防范指纹识别。

IP Leak Test

显示你的 IP 地址和相关细节：位置、运营商、WebRTC 检测、DNS 等。

EXIF Remove

官网 ↗原文

显示并移除上传照片或文档里的元数据与 EXIF 信息。

Redirect Detective

官网 ↗原文

查一个可疑网址最终跳到哪里，不必亲自点。这样能避免被广告软件或追踪站点中转，也能确认短链是否真的指向正规站，或是否属于推广链接。

Blocked.org

官网 ↗原文

检查某个网站在你的移动或宽带运营商所用过滤规则下是否被封。

Virus Total

官网 ↗原文

分析可疑的网络资源，按网址、IP、域名或文件哈希判断恶意软件类型。注意文件是被公开扫描的。

Hardenize

扫描网站并给出安全概览，涉及 HTTPS、域名信息、邮件数据、万维网协议等方面。

Is Legit?

FFmpeg

完整的跨平台音视频录制、转换与串流方案，行业标准级的多媒体框架，支持格式极多。作为命令行工具，它保证所有处理都在你本机完成。

VERT

磁盘清理13

Czkawka

官网 ↗原文

它被诚实地标注为完全没有隐私功能，而这份坦率正是恰当的定位：一个快速、免费、开源的去杂物工具，用来找重复文件和垃圾，仅此而已。作为磁盘卫生它很出色，跨平台，是付费 Mac 重复文件查找器的真正免费对手。别指望它保护任何数据，它一点也没有。纯粹为了不花钱腾空间，就用它。

BleachBit

官网 ↗原文

开源、免费，带着这里对隐私真正要紧的那项功能：粉碎文件、擦净空闲空间，让已删除的数据不再残留。这份专注既是长处也是局限，它是能擦除的清理器，不是打磨精致的优化套件。界面务实，你勾错一个框，它也会痛快地删掉你其实想留的东西。安全删除是重点时选它，想要漂亮的 Mac 优化器则不是。

ExifCleaner

官网 ↗原文

格式覆盖面是亮点：图片、视频、PDF，批量拖放，给整个文件夹剥元数据毫不费劲。正是这份广度让它在发布前清理时比单一格式的工具更该当默认。短板是只有桌面端，直接从手机分享的照片它管不到。以笔记本为工作流的发布，它是最省心的推荐。

ExifEraser

官网 ↗原文

清理需要在手机本身上完成时就选它，因为过度分享大多就发生在按发送之前。开源、MIT 许可，简单得让人舒服。局限是格式支持窄，只有 JPEG、PNG 和 WebP，视频和其他类型碰不了。作为安卓上的分享前习惯，它把这一件事做得干净，只是别把它当成你唯一的元数据工具。

CleanMyMac & PC

官网 ↗原文

一款打磨精致、对新手友好的清理器，名声靠界面和手把手，而不是硬实力。清晰的仪表盘加一键清垃圾，真能让你动手维护机器，那就值真金白银。不过要对自己诚实：它做的很多事，清缓存、卸载应用，有点耐心你自己也能免费做到。看重省事胜过省下订阅费的人，它不错。

Gemini 2

官网 ↗原文

在一件事上出色：在 Mac 上找出并删除重复文件，这份专注正是它好用的原因。只是别把重复文件查找器当成隐私工具；它回收空间，不保护数据。重复文件真的在吃掉你的硬盘、你也宁愿付钱而不想手工翻，就值；偶尔才整理一次，这笔钱很难比手动过一遍更值。

Metapho

官网 ↗原文

在 iOS 上剥元数据默认很别扭，它在分享前让你删掉或只挑掉位置数据，填上了真实的空缺。诚实的提醒是闭源，你信任的是开发者而不是自己验证行为，放在其他平台的开源替代旁边总有点不放心。想让位置信息在不上传电脑的情况下被清掉的 iPhone 用户，它是最方便的答案。看重可验证的纯粹派，仍可能偏爱桌面上的开源一遍。

Eraser

官网 ↗原文

通过用精选的模式多次覆写，把敏感数据从硬盘上彻底抹掉。

SDelete

官网 ↗原文

微软的安全删除命令行工具，采用 DoD 5220.22-M 标准覆写。

DBAN

官网 ↗原文

自包含的启动盘，用于安全擦除多数电脑的硬盘。它会自动、彻底删除能检测到的所有硬盘内容，适合批量或紧急销毁数据。它是企业级合规工具 Blanco 的免费版本。

shred

官网 ↗原文

命令行工具，可以安全删除文件与设备内容，使恢复变得极其困难。

Secure Remove

官网 ↗原文

命令行工具，用于安全删除文件、目录和整块磁盘，支持 Linux、BSD 和 macOS。

Mr. Phone

官网 ↗原文

闭源的商业手机取证数据工具套件。其中的数据擦除功能可以连上电脑后把安卓和 iOS 设备彻底擦净。
