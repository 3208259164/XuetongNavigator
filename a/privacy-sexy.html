这次介绍一个开源工具：privacy.sexy，用来在 Windows 与 macOS 上落实安全与隐私的最佳实践。

界面现代、很好上手。它有两个版本：网页版不需要在你电脑上安装任何软件；离线版功能更多，可以直接执行脚本。

它的特点

  • 丰富：数百个脚本，覆盖你对自己数据的控制权。
  • 免费：既免费使用，也开源自由。
  • 透明：启用某一项时，能完整看到这条脚本到底改了什么。
  • 可逆：觉得不对劲，可以一键还原。
  • 免安装：网页版不用在电脑上运行任何编译过的程序。
  • 开放：仓库里看到的代码就是实际运行的代码，构建与部署流程也开源、自动化。
  • 经过测试：大量自动化与人工测试，社区参与验证，稳定性改进优先于新功能。
  • 可扩展：用专门设计的模板语言就能自行扩展脚本。
  • 便携简单：每个脚本都能独立执行，互不依赖。

编者注

官网是 privacy.sexy，源码在 GitHub 的 undergroundwires/privacy.sexy。这些脚本改的是系统设置，执行前建议先看清楚每一条的作用，并利用它自带的还原功能，在改动效果不理想时恢复原状。
