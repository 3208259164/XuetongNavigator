删除与清理数据，减少隐私暴露

译自 PrivacyTools.io · 原文以 CC0 1.0 发布，译文可自由转载 · 查看原文

按前面几篇做过之后，你会剩下大量没用的数据：缓存文件、临时文件、浏览器历史、聊天记录，甚至交易记录。这些东西留着不会自己消失，一旦被人拿到就可能危及安全；除了替你记录历史，它们也没什么用处，清掉是有好处的。

动手之前先弄清哪些信息被存在哪里。可以自上而下翻一遍硬盘里的常见目录，但不知道去哪找、不确定哪些能删，这个过程会很头疼。好在有工具代劳。CCleaner 在 Windows 和 macOS 上都很常见，能清临时的网络文件、浏览记录、应用缓存和最近使用过的文件，还能擦写硬盘空闲空间，防止数据被取证恢复。我在 Windows 上常用它搭配 PrivaZer，后者思路相同但功能更多。如果只能装一个，我会选 PrivaZer。

偏好开源软件的话，可以用 BleachBit，扫描范围和清理项与上面两款不同，擦除强度相当。实际用下来，PrivaZer 加 BleachBit，或者 CCleaner 加 BleachBit，覆盖面最广。macOS 上 CCleaner 也可以用，只是苹果系统藏起来的信息比想象的多，常见需要检查的目录有：

  • ~/Library/Application Support
  • ~/Library/Logs
  • ~/Library/Preferences
  • /Library/Logs
  • /private/var/log
  • ~/Library/Caches

日志文件在控制台应用里都能看到，可以定期清掉。用户目录下的偏好设置文件里藏的信息比你以为的多：我装过的程序里大约一半会把最近文件的记录写进这些文件。有次在文本编辑器里存文件，明明已经把菜单里的最近文档选项关掉，偏好设置文件里仍然记着最近打开的那个文件。

装着旧数据的硬盘不再使用时，要安全销毁。哪怕只是换一台电脑，也建议从零开始，只把必需的文件搬过去。Windows 上很多文件存在平时想不到的地方，一个 thumbs.db 落到错误的人手里也可能带来风险。

销毁不外乎两条路，都要花时间，所以平时就把全盘加密开着更重要。一条是物理销毁：拆出磁盘，打孔、击碎，固态硬盘没有盘片，不能照搬这个做法。另一条是用 DBAN 这类开源工具把整块盘反复覆写。对安全要求高的场景，常见的做法是把 DBAN 写进一个 U 盘备用；打算继续用这块盘的，先用 DBAN 擦一遍；不打算用的，擦完再物理销毁。

编者注

原文推荐了 CCleaner。这款软件在 2017 年曾被植入恶意代码，官方随后修复并加强了发布流程，介意这段历史的话优先用 BleachBit 或 PrivaZer。另外 macOS 的用户资源库目录默认隐藏，在访达里按住 Option 点前往菜单就能看到。
