文件共享与同步9

Syncthing

官网 ↗原文

在自己的设备之间持续同步文件，中间没有云、没有账号，正是你想避开第三方服务器时要的东西。取舍在配置和拓扑：设备要你自己连，两端都得在线才能同步，出问题没有服务商兜底。想完全拥有自己的同步，它极好；指望云那样随处随时可用，就不合适。

Send

官网 ↗原文

Mozilla 那款备受喜爱的 Firefox Send 由社区接手的延续，在志愿者托管的实例上提供加密、会过期的文件链接。这里的诚实在于信任与可靠性：你依赖所选实例的运营者，社区可用率不如有资金的服务有保证。信任自己的实例或自建，做快速加密的一次性传输很好；关键任务的分享不是它。

OnionShare

官网 ↗原文

直接通过自己的 Tor 洋葱服务分享文件或托管站点，中间没有第三方，这大概是文件传输能到的私密上限。代价在便利和速度：接收方需要 Tor，你的机器全程在线，传输比普通链接慢得多。谁都不该知道有过这次传输时，它是对的工具；赶时间给不懂技术的朋友传个大文件，就不对。

Internxt Send

官网 ↗原文

从一家隐私向供应商发零知识加密文件的直白方式，免费档方便先试再定。它老实承认自己是一个更大付费存储产品的一部分，所以免费发送是通往付费方案的入口，而不是无限服务。想从一家整个卖点就是隐私的公司做加密传输，它是个公平选择；买之前把付费档和你实际的存储需求比一比。

SeaFile

官网 ↗原文

开源的云存储与同步方案。文件按资料库分组，每个库可以单独加密、共享或同步。有 Docker 镜像便于部署，Windows、Mac、Linux、安卓、iOS 都有原生客户端。

bewCloud

官网 ↗原文

用 TypeScript 写的、比 Nextcloud 和 ownCloud 更现代也更简单的替代品。把文件管理、同步、共享、笔记、订阅、开支、日历、联系人、照片统在一起，支持多因素认证、WebDAV、CalDAV、CardDAV、单点登录等。

crypt.fyi

官网 ↗原文

短暂、零知识的敏感数据分享平台，有网页、命令行和 Chrome 扩展客户端。配置项比同类私密粘贴板更多：最大读取次数、IP 或网段白名单、webhook 等。

1time.io

官网 ↗原文

零知识的一次性秘密分享，浏览器端用 AES-256-GCM 加密、HKDF 派生密钥，有命令行工具，也能用 Docker 自建。

SkySend

官网 ↗原文

端到端加密地分享 Markdown 笔记、文件、代码和密码、密钥，也能向别人索取秘密。可设口令、过期时间和最大查看次数，不需要账号。可自建，带客户端与管理命令行。

云存储11

Nextcloud

官网 ↗原文

当真正的目标是拥有自己的基础设施、而不是向厂商租隐私时，这是正确答案，规模可以从树莓派一路长到公司服务器。代价是你成了管理员：安装、更新、备份、安全都归你，这是实打实的承诺，不是下载完就完事。自建对你有吸引力、你也会维护，就选它；想要别人替你跑着的存储，托管服务是更省心的路。

Proton Drive

官网 ↗原文

来自 Proton 生态，如果你已在用他们的邮件或 VPN，想要同一把瑞士伞、同一个账号下的加密存储，这是自然之选。诚实的局限是它比 Proton 其他产品年轻，桌面端和同步客户端一直在追赶，免费的 15GB 也不算多。想把自己收拢进 Proton，它很强；若单纯按功能衡量一个独立网盘，更成熟的选项竞争力很足。

Internxt Drive

官网 ↗原文

较年轻的存储服务，MIT 许可，零知识加密，免费 1GB 长期可用，另有经过审计的方案和终身方案，这种组合不常见。实话说它比成熟玩家小也新，生态和客户端成熟度还在追赶。想要开放、加密的存储，又觉得终身定价划算，它是个公平的选择；需要深厚、久经考验的应用生态，就把它的年龄一并算进去。

Filen

官网 ↗原文

德国服务，客户端加密，免费 10GB 相当大方，流量不限，这个搭配不错。诚实的缺口是没有公开仓库可供检查，规模也小，所以你更多是在信任它的实现而不是验证它。想要放在欧盟的加密存储、还能免费试用，它是个不错选项；老牌名字会显得更有把握。

Infomaniak kDrive

官网 ↗原文

kDrive 的长处是瑞士司法管辖加上真能用的产品：桌面同步客户端、手机应用、浏览器内办公编辑，数据不经过美国或欧盟的云服务商。普通文件在静态和传输中都加密，但默认不是零知识，所以 Infomaniak 在被强制时能访问。Vault 功能为敏感文件提供真正的客户端零知识加密，但要手动开启，不是默认体验。想要一个不用自建的 Google Drive 替代品，kDrive 是稳妥之选，前提是你明白完整的零知识得用 Vault，而不是主盘。

iCloud

官网 ↗原文

开启高级数据保护后，iCloud 对大部分数据变成端到端加密，这一点领先于谷歌和微软的默认做法。短板也很实在：这层保护默认关着，要你自己打开；代码闭源，你信的是苹果的说法；公司受美国管辖。已经身处苹果生态、也会把 ADP 打开的人，选它合理。想要可审计的零信任存储，专门的加密服务商更强。

MEGA

官网 ↗原文

免费 20GB 是明显的吸引力，加密在客户端完成，理论上托管方读不到你的文件。诚实的提醒是免费方案有每日流量限制，同步大量数据就会被卡；MEGA 的过往也让一些人不太愿意把最敏感的资料交给它。作为大容量的免费通用网盘不错；把最大信任放在第一位的话，另选别家。

Tresorit

官网 ↗原文

Tresorit 站得住的地方是真正重要的那项：加密是真的，审计可信，安永、Computest、TÜV 莱茵的 ISO/IEC 27001 都在列，瑞士邮政持股意味着它在瑞士而非欧盟或美国法律下运营。短板是价格：属这一类里较贵的，客户端闭源，所以你信的是审计结论而不是自己查看代码。想要打磨好、商用级、有可核查审计记录、不用自己动手的加密云盘，选它。

NordLocker

官网 ↗原文

Nord 家族的加密存储，方案直白，500GB 与 2TB 两档，30 天退款期，冲着想要开箱即用的人去。值得点明的取舍是闭源，你信任的是公司的实现而不是自己验证。看重打磨好、有支持的产品胜过开源代码的人，它合理；把开源可验证当作硬要求，它就不是你的工具。

IceDrive

官网 ↗原文

价格很低的加密存储服务，有跨平台应用。每月 1.5 英镑起给 150GB，3.33 英镑给 1TB。

Koofr

官网 ↗原文

符合欧盟数据保护规定的存储服务，有网页、桌面、手机、WebDAV、RClone 各条路子，隐私政策合理。可选开源的客户端加密，兼容 RClone。能连接其他云服务和 MS Office。免费 10GB，服务器在德国且有 ISO 27001。

笔记与知识库13

Logseq

官网 ↗原文

先看清条款：Logseq 不加密，笔记是磁盘上的纯文本文件，所以它防的是窥探你的云服务商，防不了能碰到你机器的人。它的长处是作为本地优先的大纲工具与知识库，建立在完全属于你的文件上，没有锁定。目标是拥有数据、不落入 SaaS 孤岛，而不是防设备层面的入侵，就选它。需要真正的静态加密，这一类里它就不合适。

Joplin

官网 ↗原文

极受欢迎，5.5 万星，是 Markdown 笔记里事实上的开源选择，特殊优势是同步由你自带：Dropbox、Nextcloud 或随便什么，而不是被绑在一家厂商。短板是端到端加密要手动开启，配置比打磨过的商业应用更动手，新手容易绊住。想完全掌控笔记存在哪里、也不介意自己配同步，选 Joplin。想让笔记加密地自动出现、完全不用配置的人，该选托管服务。

Memos

官网 ↗原文

想要一个快速、零摩擦、又不喂给云服务的地方记下想法，Memos 在简单这一点上很难被超越。Go 单文件二进制内嵌 SQLite，一条命令就能起，MIT 许可意味着整套栈完全属于你。短板要说清楚：它不是加密笔记。服务器一旦被攻破，你的笔记就是明文可读。所以它对已经在跑加固基础设施的自建者是强选，对需要保密承诺却不想管自己安全边界的人则不合适。

Notesnook

官网 ↗原文

开发者开源代码之后，它现在是完全开源的了，这抹掉了过去最大的反对理由，不过巴基斯坦的司法管辖对某些威胁模型仍是问题。免费档相当大方，加密是端到端的，与 Standard Notes 正面竞争。想要富文本编辑器、能从其他应用轻松导入、第一天就不用付钱，选 Notesnook。与 Standard Notes 相比，它的审计历史更短，如果这是你的优先项，就把成熟度一并权衡。

Standard Notes

官网 ↗原文

经过审计、AGPL 授权，正是这一类该奖励的组合，对想要可验证端到端加密笔记的人，它是更稳的选择。诚实的短板是免费档故意只给纯文本：大家真正想要的功能，比如富文本和附件，都放在订阅后面。长期信任、美国团队、有审计的代码库比花哨编辑器更重要时选它，也要接受你大概会付费让它日常好用。

Cryptee

官网 ↗原文

总部在爱沙尼亚，加密在客户端完成，所以 Cryptee 确实读不到你的文档，它还能管照片，多数同类做不到。限制也实在：免费档只有 100MB，项目小、没有公开代码可查，所以你更是在信任一个半封闭的服务，而不是审计过的开源项目。想在同一个地方同时要加密文档和私密照片存储、也愿意过了免费额度就付费，它合适。笔记量大又要开源代码的，看 Standard Notes。

Turtl

官网 ↗原文

开发明显慢了下来，免费上限 50MB，体量又小，Turtl 更像一个过了高峰的项目，而不是能把日常笔记押上去的东西。它的定位是带端到端加密和简单分享的书签与笔记，需求不高的话仍可用。说实话，Standard Notes 和 Notesnook 都更活跃，今天选 Turtl 的主要理由只剩它的具体布局本来就合你意。否则从更活跃的选项起步。

Anytype

官网 ↗原文

它的架构与云优先的工具确实不同：保险库在你的设备上，同步可选且加密，即使被强制，公司也读不到你的内容。这是 Notion、Evernote 以及多数托管替代品给不了的隐私保证。诚实的短板在许可：应用是源码可见而不是开源，对客户端代码的独立安全审计有限。想要完全开源栈的自建者，Memos 或 Joplin 更合适；其他想要 Notion 级能力又有真实隐私默认的人，Anytype 是现有最可信的选项。

Org-mode

官网 ↗原文

Org-mode 是这一类里的高手上限：笔记是你完全拥有的纯文本文件，可以用 GPG 加密单条或整份文件，用 git 给所有内容做版本管理，从不碰不属于你的服务器。诚实的短板是它需要 Emacs，学习曲线陡，而且除了手机端第三方工具和其他编辑器插件，完整功能只在 Emacs 内可用。想要最大程度主宰笔记的技术型用户，没有别的能接近它。

Notable

官网 ↗原文

桌面端的离线 Markdown 笔记编辑器，界面简单但功能不少。每条笔记单独存成 .md 文件，便于管理。没有手机端、内置云同步、加密或网页界面；不过因为文件结构简单，容易接入你自己的云同步，更多功能靠扩展补。

Obsidian

官网 ↗原文

建立在本地纯文本 Markdown 文件之上的知识库，社区活跃，插件和主题很多。整体上尊重隐私，但开箱没有加密，部分代码经过混淆或不完全开源。

VNote

官网 ↗原文

用 Qt 写的免费开源笔记应用，专注于让 Markdown 写起来舒服。笔记直接以纯文本文件的形式存在本地系统里。

Poznote

官网 ↗原文

可自建的笔记与任务应用，带富文本、Markdown 和绘图编辑器，支持标签、多用户、OIDC 登录和 REST API。基于 Docker（PHP 加 SQLite），唯一的外部请求是每天检查更新。没有独立手机应用，走 PWA，也没有端到端加密。

种子下载5

qBittorrent

官网 ↗原文

多数人的默认推荐，因为它给你一个干净、无广告、uTorrent 风格的客户端，而没有原版后来沾上的捆绑垃圾。开源、跨平台，内置搜索，需要时还有网页界面。提醒其实不在应用本身：光有种子客户端对隐私毫无帮助，不配 VPN，你的真实 IP 就暴露给每一个对等端。没有特别理由要更轻或更专门的客户端，就从这个开始。

Transmission

官网 ↗原文

极简是卖点：占用小，界面几乎不存在，不挡你的路，所以它在 Linux 上、以及作为无头守护进程很受欢迎。这份克制也是局限，想要精细带宽调度和插件的高阶用户会觉得被框住。想要一个只管传文件的轻量客户端，尤其是在服务器或低配机器上，选 Transmission。想要一堆旋钮和面板的人，去看 qBittorrent 或 BiglyBT。

BiglyBT

官网 ↗原文

功能极繁主义的选择，承自老的 Vuze 代码，有 swarm 合并、大量设置、安卓远程控制，给想要每个旋钮的人。这份深度也是警告：在精简客户端旁边会显得沉重杂乱，界面也拿不到设计奖。真的需要高级控制和远程管理、并且会用，选 BiglyBT。只是偶尔下个文件，它的复杂度超出所需，用 qBittorrent。

WebTorrent

官网 ↗原文

它与名单里其余的不同，而且这点要紧：WebTorrent 讲 WebRTC，能在浏览器里串流种子，确实新奇，但也意味着该功能只能和同样支持 WebTorrent 的对等端组网，这限制了它作为通用下载器的用处。浏览器内或串流播放就是目标时选它，只是想抓文件则不是。普通的种子下载，qBittorrent 这类传统客户端能连上多得多的对等端。

Deluge

官网 ↗原文

吸引点是插件架构和薄核心，后者可作为守护进程运行，配一个独立的网页界面，对常开的环境很灵活。不过开发推进很慢，最近一次提交在三月，所以比 qBittorrent 显得没那么活跃打磨。特别想要插件模型、或客户端与守护进程分离的轻量结构，选 Deluge。没有这个需求，更热闹的客户端开箱体验更顺。
